# 过滤规则

> **这是初稿，等蔡蔡给出手工分析样本后重写。**
> 这个文件决定了整个系统的信噪比 —— 它是"品味"，不是"逻辑"。
> Claude Code 在过滤阶段读这个文件，逐条判断，不写代码。

## 目标

每天进来 150-200 条，**目标 5 条、硬上限 8 条**。宁可漏掉，不可放水。
放水的代价是每天收到一堆垃圾然后再也不看；漏掉的代价是晚几天知道，可以接受。

主目标是找**能抄、能迁移到现有业务的机制**；投资价值判断作为辅助信息，不为了
“看起来像好公司”挤掉更有可迁移价值的产品。地产、营销、内容相关产品在质量相同
时优先，但不能绕过第一档淘汰规则，也不能因为赛道相关就降低证据门槛。

## 先看来源：两类东西不能用同一把尺子

不同来源采回来的东西性质完全不同，**混在一起用同一套标准会两头都判错**：

| 来源 | 是什么阶段 | 怎么判 |
|------|-----------|--------|
| Product Hunt / Hacker News / GitHub / Hugging Face | 刚冒出来，几乎没有数据 | 走下面的三档规则，靠判断 |
| **AICPB** | 已经跑出规模，有真实访问量和环比 | **只看两件事，见下** |
| **官方博客 / 官方 Release** | 一手发布的行业变化，不一定是新产品 | 只作日报背景；不进入产品分析队列 |

**AICPB 来的产品单独处理。** 它们大多是豆包、DeepSeek、Z.ai 这种已成气候的东西，
用"已饱和品类"那条会全部误杀 —— 但它们本来就不是拿来"发现"的，是拿来看势的。

对 AICPB 的产品只问两个问题：

1. **环比异常吗？** 增速超过 +100% 的必须留下并说明原因（是真起量，还是上了什么榜、
   被哪个平台导流、还是数据口径变了）。今天最典型的是 MaxAI.me +13311%、商汤小浣熊 +3479%。
2. **是不是国产新势力？** 中国榜上首次出现、或排名跳升的，留下。

其余的（排名平稳的头部产品）**不进分析队列**，只在简报里用一行带过市场格局的变化。

**官方发布单独处理。** 它们可以解释能力、模型、平台或生态的变化，但一条公告不是新产品，
也不是“值得模仿”的充分证据。只写摘要直接支持的事实和明确可验证的影响；没有影响就不写。

## 第一档：直接淘汰（命中任意一条即出局）

- **纯提示词套壳**：核心能力就是把一段 prompt 包成 UI。识别信号：功能描述里除了"AI 驱动"说不出别的机制；官网只有一个输入框；没有任何数据、工作流或集成的沉淀。
- **已饱和品类的第 N 个**：AI 头像 / AI 女友陪聊 / AI 论文降重 / 通用 AI 写作助手 / "和 PDF 聊天" / 又一个 AI 聊天机器人聚合站。这些赛道的胜负已分，新进入者除非有极特殊角度，否则没有观察价值。
- **API 中转 / 模型聚合商**：卖 token 差价的，不是应用。
- **纯目录站、榜单站、导航站**：本身不解决问题。（注意：AICPB 自己就是榜单站，
  但我们抓的是**它榜上的产品**，不是它本身 —— 别把这条规则套到 AICPB 来源上。）
- **无独立产品**：只有 Notion 页面、Google 表单、等待列表落地页，产品还不存在。
- **明显刷榜**：票数与实际内容量级严重不符，评论清一色同质化短句。

## 第二档：优先保留（命中任意一条即进入分析队列）

- **替代了一个具体的旧工作流**：能说清"以前这件事是谁、用什么、花多久做的"。这是最强信号 —— 有旧行为就有真需求。
- **垂直行业而非"所有人"**：面向律所、货代、牙科诊所、独立站卖家这种具体人群，而不是"面向所有创作者"。垂直意味着他们真的和用户聊过。
- **定价页写得明确且不便宜**：敢标 $99/月以上并说清按什么计价的，说明验证过付费意愿。免费或 $9/月的通用工具通常还没找到价值。
- **卖结果不卖工具**：按产出收费（每份报告、每个案子、每条视频）而不是按席位/月费，说明它敢对结果负责。
- **有非 AI 的壁垒**：独家数据、线下履约、行业牌照、已有客户关系。这类产品即使模型能力被抹平也还在。
- **增长曲线异常**：短时间内流量/星数陡增且不是靠一次曝光。
- **做这件事的人对得上**：能查到创始人自己就是这个问题的受害者，或者他的经历
  和这个问题严丝合缝。采集层已经记下了 builder，这条比产品本身更能说明问题。

## 第三档：存疑但保留（记录，不展开分析）

- 中国团队做的出海产品 —— 蔡蔡关注，即使品类普通也留一条记录。
- 看不懂在做什么但数据很好的 —— 这类往往是认知盲区，值得留个名字观察一周。
- 大厂刚发布的 AI 功能 —— 不算创业公司，但会改变一批创业公司的生死，单独一节列出。

## 判断顺序

1. 先跑第一档淘汰，砍掉大部分。
2. 剩下的跑第二档，命中的进分析队列。
3. 两档都没命中的，看第三档；再没命中就丢弃。
4. 如果某天分析队列超过 8 条，先按“能否迁移到现有业务”，再按“替代旧工作流”
   信号的强弱排序，只取前 8；正常目标是 5 条，不必凑满。

## 已采用的编辑口径

- [x] 以**能抄的**（可迁移机制）为主，能投的作为辅助判断。
- [x] 地产/营销/内容相关应用在同等质量时加权，但不降低淘汰门槛。
- [x] 每天目标 5 条，硬上限 8 条；宁可不足，不凑数。
