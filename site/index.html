PiG

首次发现

2026-09-27 · 开源项目 · 软件与信息服务

这是什么

开发者在自建或受限环境里部署编码代理时，原本要处理 Pi 的 TypeScript 代码库；PiG 把上游 Pi 的 TypeScript 实现按行为对齐方式翻译成 Go，上游行为作为契约，用户拿到的是可编译、易分发的 Go 版本编码代理。具体交付流程与人工确认环节仍待核验。

本期关注理由

实质更新

2026-09-27 · 开源项目 · 医疗健康 / 生物医药 / 临床研究

这是什么

肿瘤科医生或临床研究者在查一个癌种、疗法或靶点时打开它，把原本散在文献、试验登记与机构页面里的材料交给它；它按癌症、疗法、靶点、试验、机构、人物各生成一页结构化条目，先给通俗解释再给机制与解法，并通过网页、JSON API、MCP server 或命令行返回可引用的结果，具体临床可用性与人工复核流程仍待核验。

此次变化

2026年9月公开材料显示，OnCo 以网站、JSON API、MCP server 与 CLI 形式发布一个公开、可引用的肿瘤学知识图谱，按癌症、疗法、靶点、试验、机构、人物与想法各建一页，共获得约187个收藏与31次复刻；本轮未披露定价、客户或付费数据。
