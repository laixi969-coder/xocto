stoaexchange

强烈推荐 基础层
替代了什么

买 GPU 现在的实际流程是：挨个问 OEM 的销售拿配额报价、问云厂商有没有余量、 托朋友找经纪商、在二手渠道碰运气。每一路的报价口径都不一样， 你没法知道自己拿到的价格是好是坏。

能拿走什么

产品逻辑：地产是"信息不对称最严重、单笔金额最大"的行业之一， 和 GPU 的处境结构相同。它的做法值得看：不做撮合，先做基准。 先让所有人都来看你的价格，来的人多了，交易自然发生在你这里。

shuohao-skills

强烈推荐 AI + 创作
替代了什么

短剧改编的前期工作。以前这一段是：编剧读完小说 → 手写人物小传 → 美术出设定图 → 导演排分集大纲 → 制片列资产清单。一个团队三到五人，一部剧的前期做一到两周。

能拿走什么

产品逻辑（高度相关）：这正是 songo 缺的上游环节。你的工作流是"从灵感到成片"， 而它把"从小说到可开拍素材"这一段做成了标准件。它的 13 道质量门尤其值得看—— 把创作质量变成脚本能检查的硬约束，这个思路可以直接搬到 songo 的每个环节上。

open-ai-canvas

强烈推荐 AI + 创作
替代了什么

AI 影视创作现在的实际工作流是：ChatGPT 写大纲 → Midjourney/即梦出图 → 可灵/Runway 生成视频 → 剪映拼接 → 中间用飞书文档和微信传素材。

能拿走什么

产品逻辑（直接对标）：这几乎就是 songo 的开源版本。去读它的角色资产数据结构—— 它怎么定义一个角色的"外观、声音、气质"并让这些在不同生成环节间保持一致， 这是 songo 最核心也最难的部分，现在有人把答案写在 GitHub 上了。

Gendangzou-skill

强烈推荐 基础层
替代了什么

研究员看政策选股的实际流程：读政策文件 → 判断影响哪个行业 → 翻研报找受益标的 → 查资金流验证 → 看媒体口径确认预期。 一条完整链路要花半天到一天，而且每次都要重来。

能拿走什么

产品逻辑（直接撞你的 octo）：这是你能找到的最接近的公开参照物。 特别看它的四线交叉结构 —— 政策、媒体、市场关注、资金确认， 四条独立线索验证同一个判断。这个结构比任何单一信号都稳， 而且它不只适用于股票：地产的政策、舆情、成交、资金四条线是同一个模型。

moonlit-stories

值得关注 AI + 创作
替代了什么

家长给孩子做英文启蒙的现状：买现成绘本（内容固定、和孩子的兴趣对不上）、 或者自己编故事（编得出来但画不出来）、或者用 AI 生图（每页画风不一样， 孩子会觉得不是同一个故事）。

能拿走什么

产品逻辑：「一致性」比「生成质量」更值钱，这一条直接适用于 songo。 它和影策给出了同一个答案：把角色的外观、声音、气质固化成可复用资产， 在所有生成环节里引用同一份。两个独立项目的相互印证，比任何单个案例都可信。

gtm-cofounder

值得关注 AI + 商业
替代了什么

技术创始人找一个商业合伙人，或者花钱请顾问、买课、混社群。

能拿走什么

这个产品是你的反面，所以特别值得看。 它试图把你二十年积累的那种判断力 打包成软件卖给不懂营销的人。

douyin-tiktok-story-skill-agent

值得关注 AI + 创作
替代了什么

短视频编剧找参考的实际流程：打开抖音刷同类内容 → 看到好的手动记下来 → 攒成一个自己的文档 → 下次写的时候翻半天找不到。

能拿走什么

产品逻辑（直接撞你的短剧业务）：「按结构标签检索参考样本」这个能力， 你的 songo 里应该有。特别是用「前三秒冲突」这类结构维度而不是题材维度做索引 —— 题材谁都会标，结构才是编剧真正在找的东西。

open-kimi-ppt-skill

有待观察 基础层
替代了什么

用 AI 做 PPT 的实际流程：让模型写大纲 → 自己复制到 PowerPoint → 手动排版 → 发现结构不对再回头改。中间的复制粘贴和排版是纯体力活。

能拿走什么

这一条对你有直接的实操价值：你在做 songo 和各类 skill， 里面很可能有围绕某个现成产品做的能力。这个案例给出的教训很具体 ——

值得留意

替代关系清晰，但还没展开分析
  • Argos 在浏览器里代替你操作的 AI AI + 效率

    浏览器是所有 SaaS 的公共入口，在这一层做自动化能绕开所有 API 授权
  • Rescript for Desktop 开源的 Descript 替代品，音视频剪辑全在本地跑 AI + 创作

    对标 30 美元月费的成熟产品，攻击角度是「免费 + 数据不出本机」，隐私正在变成可定价的卖点
  • Soloop 给单人创业者的审批优先型 Agent 操作系统 AI + 效率

    「审批优先」这个词组本身说明了取舍：宁可慢，也要让人保持控制权
  • StepShot 把真实操作录屏自动转成图文步骤手册 AI + 效率

    「教别人怎么做」这件事在培训、SOP、客户交付里反复出现，是同一个需求的不同壳
  • Troopr AI Scrum Master 从真实工作记录自动写每日站会汇报，还记得团队情况 AI + 效率

    从「你填表」变成「系统替你写」，这是所有汇报类工作的统一改造方向
  • Workflo Mac 工作区自动化，但从不读取你的屏幕 AI + 效率

    把「我们不看什么」写进定位，隐私正在从合规项变成营销点
