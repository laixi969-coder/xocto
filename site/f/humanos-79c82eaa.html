Humanos

Humanos 是面向 AI 智能体的风险网络：通过 SDK 与 API 持续采集智能体身份、授权、控制措施和运行时行为，生成 0–100 的动态风险评分与可验证执行凭证，并把风险画像复用于信贷、保险与审计场景。

替代什么旧工作

替代一次性问卷式 AI 风险评估、分散在各系统的人工审批与日志审计，以及事故后靠人工回溯重建的取证流程。

商业判断

最关键的商业判断是：Humanos 不卖通用 AI 治理，而是把“智能体执行证据”做成可被银行、保险人和审计方复用的风险基础设施；成败取决于能否形成跨机构的风险网络效应，而非单点监控功能。

01

产品做什么

官网披露的产品分为三层：Agent SDK 提供持续风险评分、风险历史与运行时事件接入；Controls API 覆盖身份与权限、护栏、运行时强制执行、人工授权和交易限额；Risk Intelligence API 则面向保险、银行、合规与审计团队输出定制风险信号。公司还提供 TypeScript、Python、C# SDK、MCP 集成、Webhooks 和 humanos.verify() 执行前校验。需要说明的是，应用端页面抓取失败，文档站未纳入证据，因此具体评分方法、误报率和控制项覆盖范围仍无法核验。

02

谁使用、谁付钱

使用者是部署自主智能体的工程与安全团队，付费者更可能是承担资金、合规或承保风险的机构：支付与资金管理团队、AI 责任险 MGA、智能体信贷方、医院与受监管行业的多智能体平台。痛点频率取决于智能体动作频率——资金划转、理赔、处方与授权类操作每次执行都需要身份、权限和证据，属于高频且高后果场景。官网称覆盖 350+ 金融科技、医院与保险公司，但这是公司自述，未提供可审计的客户数量或留存数据。

03

实际工作流

典型流程是：客户在智能体运行环境中安装 SDK 或接入 API，智能体在敏感动作执行前调用 humanos.verify() 校验身份与授权；运行时事件、控制措施和交易证据被持续上报，系统据此生成并更新风险评分与可验证风险画像；机构侧通过 Risk Intelligence API 查询评分、风险驱动因素和审计证据。InsureNow 案例显示，承保时客户接入智能体，风险画像每 24 小时刷新，理赔时用执行凭证还原授权范围与触发事件。

04

收费与单位经济

定价页显示风险管理层（持续评分、风险历史、运行时事件接入）免费，证明层随 Agent SDK 提供，控制层走 Controls API，Risk Intelligence 为定制报价、需联系销售。也就是说，基础监控用于获客，收入应来自机构级风险情报与集成；但具体合同金额、按调用量还是按资产/保单计费均未披露，单位经济无法判断。

05

采用证据与缺口

官网列出 InsureNow（AI 责任险承保与理赔证据）、Agentics Credit（为 Polymarket 交易智能体授信）、Numo（资金管理执行前校验）、Lusíadas（医疗授权跨系统复用）和 DataWhisper（受监管多智能体授权）五个案例，并称获 Mastercard For Fintechs 2026 竞赛。这些均为公司披露，缺少付费规模、活跃智能体数、评分准确性和客户续约证据；应用端不可访问也限制了对真实产品成熟度的判断。

06

竞争与壁垒

与通用大模型或单点护栏工具相比，Humanos 的差异在于把身份、授权、控制与执行证据串成可跨机构复用的风险画像，理论上形成数据与信任网络效应；执行凭证对保险承保和理赔尤其有结构性价值。但壁垒成立的前提是：评分被第三方认可、证据标准可互操作、且客户愿意把运行时数据交给网络——目前这些都只是公司主张。

07

如何解读这轮融资

本轮为 Seed 轮，投资方包括 Anthemis、Critical Ventures、Start Ventures 和 Springbank，说明机构愿意押注“AI 风险可承保化”这一方向；但资金用途未披露，不能推断用于产品、销售还是合规建设。下一里程碑应是证明 Risk Intelligence 有付费合同、评分被保险或信贷方实际用于定价，而非仅完成集成。

08

可能失败在哪里

第一，若风险评分无法被保险人或信贷方验证为有预测力，Risk Intelligence 就退化为仪表盘，定制收入难以规模化。第二，智能体平台与云厂商可能把身份、授权和审计内建，压缩独立风险层的空间；同时跨机构共享运行时数据面临隐私与合规阻力。第三，免费监控层可能带来高支持成本而转化不足。

09

可借鉴的做法

Humanos 的可借鉴之处是把“合规与安全”从成本项重构为可交易的资产：先以免费 SDK 嵌入执行路径，积累运行时证据，再把证据卖给需要定价风险的金融机构。对 AI 产品团队而言，关键动作是占据动作执行前的校验点，而不是事后日志。

10

下一步看什么

可验证的下一指标是：是否出现公开的付费 Risk Intelligence 合同或保险保单实际采用 Humanos 评分定价；以及官网所称 350+ 机构中活跃接入智能体数量与评分更新频率是否可被第三方核验。
