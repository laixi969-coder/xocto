01

真需求判断

真需求判断

真需求

它替代的是自己搭地理编码、或买 Google Maps 这类高价方案的行为，开发者需要把文本里的地名转成坐标，这是持续性的技术需求。付费客户从 2017 年 12 月 1 个增长到 2018 年初每月新增数个，说明有人反复付钱。

如何赚钱

两条收入：一是在 AWS Marketplace 上按小时出租软件实例，价格 0.10 到 6.00 美元/小时，AWS 负责客户关系；二是直接卖 API 访问，有 200 欧元/月的无限量套餐和按量付费。

它替代了什么旧行为

自建地理编码，或使用 Google Maps Platform 等更贵的商业 API。

02

首批用户来源

第一个非付费用户是 2016 年一位分析推特数据的记者；第一个付费客户出现在 2017 年 12 月，来自一个态势感知应用。早期流量靠从 geocoder.ca 挂链接导入。

获客渠道 geocoder.ca 导流AWS Marketplace会议演讲论坛口碑链接

03

可借鉴的打法

  1. 01把新产品挂到已有老产品的页面上导流，用现成流量冷启动。
  2. 02上架 AWS Marketplace 按小时出租，把客户关系和收款交给平台，自己只维护软件。
  3. 03定价刻意低于最接近的竞品，用简单低价换量，而不是跟着涨价。
迁移到 AI 生意

对做 AI API 的开发者：把模型能力包成按量或按小时计费的 API，上架云市场让平台代管客户和收款，是独立开发者低成本起步的一条路；低价切入、靠调用量而非单价赚钱同样适用。
