01

真需求判断

真需求判断

真需求

合盖继续运行是 Mac 用户长期存在的真实痛点，过去要靠外接显示器或改系统设置绕过；现在 computer-use agent 需要机器长时间不合盖休眠，需求更硬。已有 Stripe 验证的持续付费。

如何赚钱

用户直接为这款 Mac 应用付费，收入通过 Stripe 收款，当前月收入约 310 美元。素材未说明是一次性买断还是订阅。

它替代了什么旧行为

过去靠外接显示器、改电源设置或第三方常亮工具来防止合盖休眠。

03

可借鉴的打法

  1. 01把产品定位钉在一个具体的新场景上（computer-use agent 长时间跑任务），而不是泛泛的『让 Mac 不休眠』
  2. 02用无需管理员密码、无需特权 helper 作为卖点，降低安装门槛和信任成本
迁移到 AI 生意

对做 AI 生意的人：当 agent 需要长时间无人值守运行时，围绕『让宿主机器别掉线』这类底层摩擦做小工具，是能直接收费的窄切口；把卖点绑在 agent 场景上比绑在通用系统工具上更容易被搜到。
