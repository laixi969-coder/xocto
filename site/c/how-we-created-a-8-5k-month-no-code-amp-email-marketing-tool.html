01

真需求判断

真需求判断

真需求

它替代的是传统 HTML 邮件加落地页的转化路径，把表单和交互直接放进收件箱。Razorpay 的对照测试显示交互邮件转化率是 HTML 邮件的 3 倍，说明付费理由来自可量化的转化提升，而非概念。

如何赚钱

向企业营销团队收 SaaS 订阅费，按邮件量或功能分层收费；素材未给出具体定价档位。

它替代了什么旧行为

传统 HTML 邮件加跳转落地页才能完成表单填写和转化的旧流程。

02

首批用户来源

第一批客户来自创始团队直接接触的营销人和邮件专家，首个付费验证客户是 Razorpay。

获客渠道 Product Hunt 发布邮件营销社区与论坛行业影响者与播客早期用户转介绍

03

可借鉴的打法

  1. 01用 A/B 对照测试证明效果：在同一批名单上同时发 AMP 邮件和 HTML 邮件，用转化率差值说服早期客户。
  2. 02先手工硬编码邮件服务试点客户，边交付边积累 AMP 实现经验，再把这些经验产品化成无代码编辑器。
  3. 03把 Product Hunt 发布当作冷启动主渠道，同时收集反馈用于迭代，而不是只求曝光。
迁移到 AI 生意

对 AI 应用同样成立：找一个平台级新能力（这里是 AMP），在它还没被工具化时先做无代码封装，并用对照实验量化效果作为销售弹药。AI 产品可以把『模型能力 vs 旧流程』的 A/B 数据做成标准销售材料。
