使用场景

开发者在离开工位时，需要连回自己的机器查看编码 agent 的运行状态，并在必要时进入终端处理卡住的会话。

开发者目前靠远程桌面、SSH 客户端或干脆等回到电脑前再检查。

agent 跑在本地机器上，人离开后无法判断任务是否完成或报错，只能等回到电脑前才发现。

xOcto 的判断

问题已识别，需求强度未明

趋势是编码 agent 常驻在开发者自己的机器上，远程查看与接管开始成为独立需求。切入可考虑为需要离开工位但仍要盯住 agent 的独立开发者或小团队做远程状态与终端入口，前提是 SSH 直连方案在移动网络下的稳定性得到验证。
