值得借鉴的一点

自定义基准测试让模型评估更贴近实际业务，可迁移到垂直领域选型。

它替人省掉了哪一步

以前选模型有两条路，都不好用。

可借鉴的做法

产品逻辑：如果你在做任何"帮用户做决定"的产品，把决定权交还给用户的具体任务， 而不是提供一份平均分。平均分只能引流，私有评测才收得到钱。

一句话定位

把"用通用榜单选模型"改成"用你自己的任务造一个基准，跑完直接看分数、成本和时延"， 让模型选型从拍脑袋变成可复现的测量。

做这个东西的人

Artificial Analysis，一家独立的第三方模型评测公司，由 George Cameron 联合创立。 长期运营模型智能指数（Intelligence Index，现 v4.1）和各类榜单，公开评测 150+ 模型， 2026 年中还推出了按 O*NET 职业分类加权的六个行业指数（金融、法律、医疗、运营、工程、经济）。

判断：选型评测是它的老本行，Optima 是把自家评测能力产品化的一次尝试。 它不是从零做的新玩家，而是给已有的权威榜单加了一个"你自己来造"的出口。

它到底能做哪几件事

  • 造自己的基准 → 描述任务、上传示例、导入自己的对话轨迹，或让构建 agent 起草任务和评分标准（rubric），支持小批量（示例页展示 24 题）
  • 四种评测类型 → Q&A（有标准答案）、文档问答（基于上传文件）、Agentic（用工具完成交付物）、Interaction（模拟真实对话，coming soon）
  • 横比多家模型 → 跑完后给出每个模型的分数、单任务成本、单任务时延；也支持把自己的 agent 通过 HTTP 接入同一场评测
  • 两种评分方式 → 按自定义 rubric 逐条评分，或用评测界常用的 judge 模型做两两对比

它明确不做：不造新模型，不造新基准集，也不替你做"该选谁"的决策——它只把评测这件事标准化。

它在替代什么旧行为

以前选模型有两条路，都不好用。

一条是看通用榜单：MMLU、智能指数这类平均分。它对"我要做合同审阅"这个具体场景没有区分度—— 榜首模型不一定在你的任务上最好，但平均分让人误以为它最好。

另一条是自己搭评测：写一版 eval 脚本，接 API，用你自己的几十条样例跑一遍，再手工比对输出。 每个团队都重复搭同一套东西，搭完还没人维护，下一轮模型发布又得重跑。

Optima 替代的是第二条里的全部脏活：样例组织、rubric 编写、批量跑分、结果汇总。 把"搭一次评测"的成本从以人日计压到以 token 计，把"选型靠榜单"变成"选型靠你自己的任务"。

商业模式

按用量收费：跑基准按所用模型的原始 token 成本计费，"不加任何加成"（官方原话）； rubric 评分每个标准、每条模型 $0.125；两两对比评分每对 $0.375。 各阶段先按预估冻结信用额度，结束后只扣实际用量。

判断：这是"评测即服务"的定价——赚的不是跑模型的差价，而是评分和评测组织费用。 有意思的是评测者自己成了评测的裁判之一，这在信任上需要长期维护。

硬数字

四维评估

维度 结论

判断

这是把"评测"从一个公共产品变成一个私有工具。 公共榜单的价值在于横比， Optima 的价值在于竖比——只回答"你的任务上谁最好"。两者不冲突， Optima 反而给榜单吸引了更多愿意自己动手的用户。

可迁移的规律：评测权归用例，选型才成立。 任何一个要反复选供应商的场景 （云、模型、API、甚至外包团队），都可以造一套"用你的真实任务打分"的评测流程， 而不是信任一份公共排名。公共排名平均掉了对你最重要的那一维。

风险在于"谁评裁判"。 评测公司同时做评分工具，长期看信任取决于评分是否可复现、可审计。 rubric 逐条评分比两两对比更可审计，这个设计是对的。

另一个问题：评测是一次性的还是持续的？如果每轮新模型发布都要重跑， Optima 的价值随使用频率线性增长；如果只是选型时用一次，它就是一个低频工具，市场天花板有限。

下一步看什么

① Optima 的付费评测量三个月内有没有公开的增长数据（跑过的基准数、企业客户数） ② 评测结果能否导出可复现的报告（评分方法、judge 模型、版本号）——这决定它能不能进入企业的正式选型流程 ③ 它会不会把"agent 自己造基准、自己跑评测"纳入主流程——这才是真正改变工作方式的地方

可借鉴的做法

产品逻辑：如果你在做任何"帮用户做决定"的产品，把决定权交还给用户的具体任务， 而不是提供一份平均分。平均分只能引流，私有评测才收得到钱。

话术：值得抄的是定价表达——"按原始 token 成本计费，不加任何加成"加"每标准 $0.125"， 把成本拆到可感知的粒度，比"按用量计费"可信得多。

定价结构：把评分和算力分离定价，赚组织层的钱而不是算力差价。

结论

持续观察。 公司可信、方向成立、切入的是真痛点。但 Optima 刚上线，HN 反响平平， 付费数据和评测可复现性都还没被证明。记下来，拿上面三条验证。
