一句话定位

Mac 上的磁盘空间分析工具，但把"五彩地图"换成了"一张密实的表格"——本地磁盘、OneDrive、Google Drive、SSH 服务器一次扫完，目录大小、已分配空间、占父级百分比、文件数、文件类型合计全在一棵表里看。

做这个东西的人

独立开发者 puppypi（PH 上就这么署名）做的，开源项目，AGPL-3.0，Tauri + Rust + React，扫描引擎基于 pdu。2026 年 8 月 9 日在 发布平台 上线，108 票，当日第 12。苹果公证过，也上了 Mac App Store。

判断：单开发者 + 开源 + 上架 App Store，这是独立 Mac 工具的标准打法。值得注意的细节是它同时走两条分发通道——MAS 版受沙箱限制（只支持本地盘、OneDrive、SSH），公证直装版额外支持 Google Drive 和系统 SSH 配置——说明作者知道 App Store 的限制在哪，提前留了后路。

它到底能做哪几件事

  • 表格优先的树视图 → 仿 Windows 上 WizTree 的思路：一棵密实的树，同时显示大小、已分配空间、父级百分比、文件/目录数、文件类型合计，下钻时信息不消失
  • 本地 + 云端 + 远程一次扫 → 本地磁盘、OneDrive、Google Drive、SSH 路径同一套界面
  • 云端只读元数据 → OneDrive 走 Microsoft Graph delta 增量同步 + 本地元数据缓存，不下载文件内容；Google Drive 走 OAuth，也是元数据级
  • SSH 用系统配置 → 复用 ~/.ssh/config 和 Keychain 里的密码，不用在应用里另存凭据
  • 清理安全 → 清理先暂存给你审；云端删除进回收站，本地/SSH 永久删除要二次确认
  • 大表性能 → 行虚拟化、结果缓存、增量刷新，几百万行的目录树不卡

为什么是表格而不是地图：作者在 PH 上把动机写得很直白——"大多数 Mac 磁盘清理工具画一张漂亮的菊花图，但我最后还是要问：到底是哪个文件夹占着这块空间？分配了多少？里面几个文件？什么类型占大头？"

它在替代什么旧行为

Mac 上清理磁盘以前是两个选择：

一是 DaisyDisk / OmniDiskSweeper 这类图形工具——把所有文件画成一圈圈彩色圆弧，一眼看到"大头在哪"，但只适合"定位大头"这一个动作。想回答"这个目录到底几个文件、各类型占多少、它在我整个盘里占多少比例"这种结构化问题，图形工具不给答案。

二是 命令行——du、ncdu、find | xargs 之类，信息全，但输出停在终端里，对普通用户不友好，也没法对着表格逐级下钻和动手清理。

DuckDisk 替代的是这两者之间的空档：把 WizTree 在 Windows 上验证过的"表格优先"体验搬到 Mac，同时把本地、云端、SSH 三种来源并到一棵树里。它的洞察是——图形地图适合"猜"，表格适合"查"，而清理磁盘这个动作本质上是反复"查"。

判断

这是"老工具换个数据呈现方式就是新产品"的教科书案例，但天花板也一眼看得到。

DuckDisk 的产品洞察值得单独拎出来：图形地图和表格是两种完全不同的思维——地图回答"哪里大"，表格回答"什么占、占多少、怎么下钻"。后者天然适合做决策，前者天然适合做演示。它在"回答结构化问题"这件事上确实比所有 Mac 图形工具都强。

可迁移的规律：不要只做"看得见问题的界面"，要做"能回答问题的界面"。 大多数分析工具的第一版都是"把数据画出来"，但用户真正要问的问题往往是结构化的——哪个、多少、占百分之几、和谁比。先列出用户会问的 5 个具体问题，再决定用表格还是图表呈现，比先选一个漂亮的默认形态靠谱得多。

它的天花板在于：磁盘清理是个低频、免费、被系统自带工具教育的市场。它没有网络效应、没有生态、没有数据积累的壁垒，一个比它更便宜或更漂亮的竞品就能把用户接走。它的价值不在这个产品本身，而在"独立开发者用一套工具链（Tauri + Rust + 开源 + MAS）能做出多完整的产品"这个示范——对想自己做 Mac 工具的人来说，这个示范比 DuckDisk 能清理多少磁盘更值钱。

① 三个月后 star 数和 App Store 评分/评价量——衡量"免费工具"的口碑积累速度 ② 作者会不会推出付费 Pro 档（云端多账户、报告导出）——判断免费是真的策略还是没想好 ③ 有没有被邀请进 Setapp/第三方 Mac 工具合集——这是独立工具变现的常见路径

可借鉴的做法

产品逻辑：做任何分析型工具，先写出一张"用户会问的问题清单"，再用数据形态去逐条回答。DuckDisk 的整张表就是 5 个问题的答案集（谁占空间、分配多少、占父级多少、几个文件、什么类型）——表格不是审美选择，是答案密度最大化的结果。

话术：作者在 PH 上的第一人称动机陈述——"我最后还是得问：哪个文件夹占着空间？"——比功能列表真诚得多。自述痛点 + 你的解法，是独立工具发布时最有效的开场白。

定价结构：无。免费开源，未披露任何商业计划。

结论

值得关注。 产品洞察清晰、工程完整、免费开源的口碑路径走得扎实，但它是一个没有商业化迹象的存量市场工具。看它的价值，一半在看工具本身，一半在看独立开发者示范——三个月后拿上面三条验证。
