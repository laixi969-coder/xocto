60 秒生意判断 · 先给出判断与下一步，再保留完整证据和反例。

一句话定位

一条悬在 Mac 程序坞旁边空白处的虚拟 LED 灯带：你的 AI agent 在跑、 在等你、跑完、还是挂了，扫一眼就知道——纯软件，不占 Dock，不读任何内容。

做这个东西的人

leog（GitHub: leog），独立开发者。项目受硬件小配件 SidePulse 启发， 把它做成纯软件。从提交记录看是和 Claude（Anthropic）结对编程完成的， 多数字段作者是 AI，仓库已有 27 个提交。

判断：这是典型的"个人工具开源出来"项目——作者的痛点（不知道后台 agent 到哪一步了）具体到值得写一个完整 app 解决，但定位始终是个人效率周边， 没有商业化意图。

它到底能做哪几件事

  • 五种状态一个灯带 → 工作中（青色彗星扫过）/ 需要你（橙色呼吸）/ 失败（红色双闪）/ 完成（八灯全绿）/ 空闲（极光流动），另有关闭态
  • 不区分模型 → 刻意用单一聚合信号，不显示是哪个 agent，只看"现在有没有事在发生"
  • 完全不嵌入 Dock → macOS 没有公开 API 支持 Dock 配件，它实现为紧贴 Dock 的无边框非激活 NSPanel，用公开屏幕几何信息（NSScreen.frame vs visibleFrame）计算位置
  • 零权限 → 无私有 API、不需要辅助功能权限、不需要屏幕录制权限、不做任何注入
  • 本地回环服务 → 监听 127.0.0.1:7455，启动时生成 Bearer token 存进钥匙串，CLI（aipulse）凭 token 上报状态，token 不进入 shell 历史
  • 接入方式 → 官方做的是 Claude Code 的 Hook 适配器，另有 pi 扩展（aipulse-pi.ts），未来可接其他 agent

它明确不做的：不读提示词、不读终端内容、不读编辑器内容、不做任何拦截或记录。

它在替代什么旧行为

以前用桌面 agent（尤其是 Claude Code 这类命令行 agent）的时候，确认 "它干到哪了"只有两个办法：

一是把终端窗口一直开着——眼睛盯着滚动日志，稍微走神就不知道 卡在哪一步，该不该等也不知道。

二是切过去戳一下——不停切窗口看输出，或者干脆盲等； agent 在等你审批的时候你不一定知道，可能干耗好几分钟。

再往前，有人买 SidePulse 这类硬件灯条来解决同样的问题——但要多花一笔钱， 占一个硬件位置，只适配特定生态。

AI Pulse 替代的是"反复查看 agent 状态"这个动作：把"它在忙 / 它在等你 / 它挂了"从日志里捞出来，变成余光就能扫到的环境光。它解决的不是功能问题， 是焦虑问题——这个定位它自己说得很清楚。

商业模式

无。 MIT 开源，免费，没有收费计划、没有付费版、没有广告。

判断：这类工具没有商业想象，价值在别处——它验证了一个洞察： agent 不可见时的心理成本是真实存在的，而且可以用 30 行 UI 解决。 这个需求将来大概率被 Claude 这类 agent 产品自己内置掉。

判断

这是一个"解决心理问题而不是功能问题"的干净样本。 大多数 agent 工具在加功能，它在减噪音——把"agent 在干嘛"压缩成一个 余光信号。聚合信号（不区分具体 agent）这个设计尤其聪明： 用户要的不是细节，是"现在需不需要我"这一个答案。

工程上它做得很认真。 不占 Dock（因为技术上不可能）、零权限、 token 走钥匙串、本地回环——一个"假灯带"按生产级标准做，这本身就说明 作者在乎质量。

但它的命运大概率是被内置。 状态可见性是 agent 产品体验的一部分， Claude 这类产品迟早自己把状态做得比第三方更好。这决定了它只能是 "过渡期的好工具"，而不是一门生意。

可迁移的规律：给"看不见的过程"加一个环境可见的信号，是最便宜也最有效的体验升级。 用户对后台进程的焦虑是真实的，而解决焦虑的 UI 往往只需要一个状态灯。

下一步看什么

① 三个月后 stars 是否破 300——周边工具的扩散速度能看出它是否被真实使用 ② 是否出现对 Claude Code 之外 agent（Codex、Cursor 等）的官方适配——决定它能不能活过过渡期 ③ 桌面 agent 官方是否上线状态灯功能（被内置的信号）

可借鉴的做法

产品逻辑：做工具时先问"用户此刻的焦虑是什么"，再问"要加什么功能"。 给后台运行的 agent 一个环境光状态，是"减噪"思维——有时候产品升级是 让用户少知道一点，而不是多知道一点。

话术：无。README 是工程文档，没有可偷的营销句式。

定价结构：无。未披露，纯免费。

结论

有待观察。 洞察好、工程干净、是真实可用的工具，但没有商业模式， 且大概率被大厂产品内置。它的价值在于示范"状态可见性"这个体验点， 三个月后看扩散速度即可——不需要把它当生意研究。
