使用场景

做摩洛哥本地研究或公共数据分析的分析师、地理信息工程师，在需要市镇级人口与边界数据时，按 HCP 编码调用 HTTP API 或 MCP 服务器，取回 2024 与 2014 年普查数据和边界，把结构化结果直接接入分析或制图流程。

旧做法是直接从 HCP 等官方渠道下载普查表格与边界文件，再自行做编码匹配、年份对齐和格式转换；或依赖零散的数据集副本，缺少统一的 API 与 MCP 接口。

摩洛哥 1,503 个市镇的普查数据与边界分散在 HCP 等官方来源，编码口径、年份版本和几何边界需要人工对齐；研究者若自行抓取、清洗和匹配，会反复消耗时间，且容易在编码或边界版本上出错。
