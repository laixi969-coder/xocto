它为什么会被需要

从用户的一天开始 · 公开事实 + 可观察行为 · 2026-10-10

使用场景

知识工作者、法务或研究助理在需要把一批 PDF、扫描件和 Office 文档喂给大模型或检索系统时，先在本机把这些文件转成结构干净、可直接投喂的 Markdown 文本。

旧做法是手工复制粘贴整理，或使用在线 PDF 转 Markdown 服务、通用 OCR 工具，以及直接让模型读取原始文件；这些方式要么费人工，要么把文件传出本机。

公开材料显示痛点在转换环节：PDF 与扫描件版面复杂，直接投喂模型会带入乱码、错序和表格错位，用户要么手工复制整理，要么把敏感文档上传到第三方转换服务，前者费时后者有合规顾虑。

xOcto 的判断

需求有依据

趋势：把非结构化文档变成模型可读文本，正在从云端 API 变成装在个人电脑上的本地步骤，敏感材料不必出本机。切入：从律所、审计、医疗档案这类不能上传文件的场景进入，卖点不是转换本身，而是本地处理加可核对的转换记录；具体流程与交付仍待核验。

使用理由

为什么用户会选择它

推断：相较在线转换或手工整理，InkDoc 把 MarkItDown、Docling、GLM-OCR 等转换器封装成本地桌面应用，用户不必先把文件上传到外部服务，也省去逐页复制粘贴这一步，因此对处理合同、卷宗等敏感材料且需要批量投喂模型的人更有吸引力。
