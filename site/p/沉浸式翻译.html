一句话定位

把网页、PDF、视频字幕从"整页替换成译文"变成"原文译文并排对照"—— 看懂原文和学习语言两件事同时发生，而且保留原排版。

做这个东西的人

独立开发者 Owen（owenyoung）做的。2022 年 10 月上架浏览器扩展，2023 年 5 月 被推文科技收购，双方成立独立子公司运营，Owen 继续负责产品与技术。 2024 年末入选 Chrome 官方年度最佳扩展。

判断：这是典型的"独立开发者 + 一次对的收购"样本。收购没有杀死产品， 反而给了它商业化的组织和资本，Owen 继续做主——这是独立产品被收购后 最常见也最难得的存活方式。

它到底能做哪几件事

  • 网页双语对照（核心）→ 原文译文并排，不覆盖原文
  • 文档翻译 → PDF 保留原始排版，EPUB 电子书
  • 视频字幕 → YouTube、Netflix 等平台双语字幕
  • 会议翻译 → Zoom、Google Meet、Teams 实时翻译
  • 图片与漫画 → OCR 提取 + 翻译
  • 输入框翻译 → 写外语时即时翻译
  • 引擎自选 → 内置 20+ 翻译引擎（ChatGPT、DeepL、DeepSeek、Gemini 等）， 用户可切换，也可用自己的 API key

它明确不做：不做自己的翻译模型。沉浸式翻译本质是一个"引擎聚合与 交互层"——翻译质量交给各家引擎，它只负责把翻译结果以对照的方式 摆到你眼前。

它在替代什么旧行为

以前浏览器里翻译网页，默认是"译文覆盖原文"：Chrome 自带翻译、老一代 插件都是整页替换，原文没了、排版错乱，想对照学语言根本做不到； 要精确翻译，就得把段落复制粘贴到翻译网站，来回切窗口。

沉浸式翻译把"原文 + 译文"并排呈现，一次解决"看懂"和"学语言"两个需求， 还保留 PDF 排版。它替代的是"全文替换式翻译 + 复制粘贴到翻译工具" 这套旧工作流。

商业模式

Freemium。网页翻译免费且无限量；Pro 版 14.99 美元/月（124.99 美元/年）， Max 版 34.99 美元/月（289.99 美元/年），主要解锁更高的 OCR 精度、 视频/图片/批量处理额度与高级引擎配额。收购金额未披露。

判断：定价卡在"翻译工具"这个品类的心理价位带内，比企业翻译软件便宜， 比免费工具贵得有理有据——OCR 和批量额度是能感知的硬差异。

判断

"一个决定吃五年"的产品。 对照式翻译不是新技术，但没人认真在浏览器 场景里做过。沉浸式翻译证明：一个交互层面的小创新，如果能打中高频场景， 足够让一个独立开发者的产品活下来、被收购、再增长。

它选对了生态位：不做模型，做聚合层。这让它永远跟得上最好的翻译引擎， 不必承担模型研发成本，也能让用户用自己已有的 API key——成本敏感用户 和高质量用户都能留在这。

增长是稳的，但天花板要盯。 mom +0.52% 说明存量用户很黏，但也没有 爆发性增长。威胁来自三面：大厂浏览器原生翻译越来越强；对照式交互已被 同类产品复制（差异化正在消失）；它本质是"翻译质量+排版"的薄价值层， 一旦引擎能力被大厂整合进系统，中间层会被压扁。

用户数口径混乱是要点名的：官网自称 2000 万+，第三方说 1000 万级， 两者差一倍。做判断的人应当以第三方可验证口径为准。

下一步看什么

① 用户数口径能否统一——2000 万（官网）与 1000 万（第三方）差一倍，官方 是否给出可验证的披露 ② 订阅转化率与收入规模是否披露——这是验证"小而美"能否长大的关键 ③ 大厂浏览器原生对照翻译是否跟进——如果 Chrome/Edge 直接内置对照模式， 中间层的生存空间会被大幅压缩

可借鉴的做法

产品逻辑：翻译/工具类产品，优先做一个"交互上的创新"而不是"能力上的 创新"——能力会被大厂碾压，交互创新（对照式）能建立品牌和习惯。 同时坚持"不自己造引擎"，做聚合层，把成本与选择权交给用户。

话术："沉浸式"把"不破坏原页面排版"翻译成一个用户能感知的体验词—— 用一个词把技术特性变成体验承诺，可迁移到任何工具产品。

定价结构：免费保住口碑与传播（网页翻译无限免费），Pro/Max 按用量场景 （OCR、批量、字幕）分层收费。免费层大方、付费层有硬差异，是工具类 产品最稳的收费结构。

结论

值得关注。 一个交互决定撑起一款全球工具，用户黏性真实，团队克制。 真正的分水岭是大厂浏览器会不会内置对照翻译——在此之前，它是独立翻译 工具里最健康的那个。
