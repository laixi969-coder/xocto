03

60 秒生意判断

先给出判断与下一步，再保留完整证据和反例。

一句话定位

把你在 Mac 上的真实操作录下来，AI 当场整理成图文分步手册， 本地处理、一次性买断，不绑账号不上传。

做这个东西的人

独立开发者 Thomas Ellon（发布平台 上自称 Stewie），单人项目。 2026-08-07 自猎发布，91 票、日榜 #18，官网 stepshot.app。

判断：发布文案里那句"花一小时去描述四分钟的操作"是真实的，每个写过教程的人都认。 他把"浏览器插件做不了这事"当成主要竞争点——Scribe、Tango 这类主流竞品都是浏览器扩展， 流程一旦涉及系统设置、原生 App 或终端就失效，这是桌面应用少有的站得住脚的差异化。

它到底能做哪几件事

  • 事件驱动捕获：监听点击和按键，每次有意义的动作生成一步，截图取"点击前那一帧"（按钮还没弹菜单的帧，而不是弹开菜单的帧）
  • 录屏模式：连续 H.264 视频 + 光标停顿自动分段，保留完整视频当证据
  • 本地 AI：用 macOS Vision OCR 和 Accessibility 树生成步骤标题（能写出"点击 Save Draft"而不是"点工具栏第三个按钮"）、智能裁剪、判断哪些步骤该保留哪些该跳过
  • 编辑器：重排、合并、跳过、标注；涂黑是不可逆的——敏感区域降采样再升采样、烙进位图，不是能剥离的模糊层
  • 导出：PDF / Markdown / HTML，三个格式共用同一个渲染器，预览即导出
  • 隐私：无账号、无遥测，密码字段在引擎层排除、字符永不进内存；云端 AI 润色默认关闭，要用就接你自己的 OpenAI 兼容端点

它明确不做：Notion 导出、自动翻译、云同步、团队账号；Windows 只是私有测试版。

它在替代什么旧行为

以前做一份教程或 SOP，是一条纯手工流水线： 把操作执行一遍 → 逐屏截屏 → 裁剪 → 画箭头 → 编号 → 写说明 → 排版。 四分钟的操作，文档要写一小时。工具层面替代的是"截屏 + 人工拼装"（Snagit 那套） 和"录屏后再手动分帧"；人替代的是技术文档工程师、支持团队、实施顾问花在 文档上的大块时间，而且手工文档通常写完就过时。

商业模式

一次性买断：Pro $129，Team $599（5 席位），永久授权、含未来所有版本。 免费版不是试用：捕获和编辑无限且永不过期，导出只限前 10 步（Markdown/HTML）。 无订阅。付费用户数、收入：未披露。

判断：买断定价对独立 Mac 工具是健康的选择，但也意味着没有经常性收入来支撑后续开发， 产品的可持续性完全取决于口碑传播速度。

硬数字

  • 发布平台 2026-08-07 发布，91 upvotes、5 comments，日榜 #18
  • 独立第三方评测（pidune，实测 3 天）：3.5/5——12 步流程识别对 11 步； 一次 45 步录制中崩溃、autosave 只恢复最后 12 步；复杂文档仍需 15-20% 后期处理
  • macOS 14+，Apple Silicon + Intel，已签名公证；界面支持英文/简体中文/日文
  • 团队规模：1 人；付费用户数：未披露

四维评估

维度 结论
创始人-产品匹配度 自己反复被"写教程"这件事折磨才做的，痛点真实，且写得出具体到帧的产品决策
产品洞察力 "预览即导出""AI 只是润色层不是生成器""涂黑必须是破坏性的"——三个决策都干净
技术实现质量 原生 macOS、无遥测、密码引擎级排除，工程上像正规产品，不像 demo
市场时机 竞品 Scribe/Tango 已教育好市场，但它们是浏览器扩展；桌面原生差异化成立但盘子小

判断

产品决策是这批小工具里最干净的之一，商业验证却是零。 三个可迁移决策值得记： "预览即导出"（编辑器、预览、三个导出器共用同一渲染器，杜绝"预览一张图、导出另一张图"）、 "AI 放润色层"（本地先生成完整草稿，模型只改措辞，绕开数据外泄的销售阻力）、 "涂黑不可逆"（不给用户可剥离的假安全）。

命门是错配：SOP 工具的真实买家是公司里的文档团队，要的是团队协作、云同步、 跨平台；而 StepShot 是单人、Mac-only、无团队账号。个人知识工作者会喜欢它， 但个人知识工作者很少为 $129 的文档工具买单——这是它要在自由职业者/独立顾问 （一人出文档交付客户）里找付费，而不是在企业里找。

竞品压力：Scribe 免费起步、浏览器内即装即用，StepShot 需要系统权限、 macOS 14+，免费档还卡导出步数。差异化的前提是用户承认"浏览器扩展不够用"， 这个教育成本要它自己付。

下一步看什么

① 三个月后是否披露付费用户或出现独立评测数量增长——买断工具没有增长数据就只有口碑 ② Team 版（$599）是否出现真实购买——公司采购才说明替代行为在企业成立 ③ Windows 版本是否转正——不做 Windows 就锁死在 Mac 份额里

可借鉴的做法

产品逻辑：任何"AI 自动生成文档/内容"的工具，先本地生成完整可用的草稿， 再把 AI 放在润色层（用用户自己的 API key）。既绕开"数据外泄"这个销售阻力， 又避免模型幻觉污染主流程——AI 是锦上添花，不是地基。

定价结构：免费版不限功能、只限导出步数——把付费点放在"输出完整性" 而不是"功能解锁"，对内容生产工具是更诚实、更合理的分层。

话术：无特别可偷的句式，它的发布文案靠具体细节（"截图取点击前那一帧"） 而不是口号立住可信度。

结论

有待观察。 产品层面的决策干净，但商业验证为零，且受众（公司文档团队） 与工具形态（单人 Mac 应用）存在错配。记下来，三个月后拿上面三条回头验证。
