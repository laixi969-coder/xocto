使用场景

使用 Claude Code 或 Codex 的开发者，在需要复用几天前某次会话里已确定的方案、改动或结论时，打开本地工具检索历史会话，找回当时的结论与代码上下文。

手动翻终端历史、复制粘贴到笔记，或重新向助手描述上下文。
