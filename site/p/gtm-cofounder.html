一句话定位

给没有合伙人的技术创始人当营销脑子：谁会买、为什么付钱、怎么开口。

做这个东西的人

GitHub 组织 AIDevGTM，官网 gtmcofounder.com。

README 的开场不介绍功能，而是这么写的：

"如果你是一个自掏腰包、熬夜和周末都投进去的技术创始人，没有融资、没有团队、 没有商业合伙人，有些日子就是单纯地难熬——那这个是给你的。尤其是给你的。"

判断：写这段话的人自己经历过。这是最强的创始人-产品匹配信号， 而且它出现在第一屏，说明作者知道这才是他真正的卖点。

它到底能做哪几件事

一组喂给 AI 编码 agent 的 GTM skills（开源，MIT）：

  • 描述你的产品 → 逼你回答"这到底是给谁的"，把模糊的目标用户逼成具体的人
  • 描述你的功能 → 推演"他为什么会为这个付钱"，找出真正的付费理由而不是功能列表
  • 给一个销售场景 → 给出开口的话术结构和该问的问题
  • 走一遍框架 → 输出常见陷阱清单，提醒技术创始人容易踩的坑

它明确不做什么：不替你做决定。 它给的是提问顺序和检查清单，不是"你这个情况应该选 A 还是 B"。 而那恰恰是客户真正想要的东西 —— 这条边界决定了它的天花板。

它在替代什么旧行为

技术创始人找一个商业合伙人，或者花钱请顾问、买课、混社群。

旧行为的成本极高：合伙人要分股权，顾问按天收费，课买了也没人回答"我这个具体情况怎么办"。 而痛点的频率是每天——他自己说的是"凌晨两点没人可以商量"。

痛的时候损失的不是钱，是方向。 这类痛最真，因为它无法拖延也无法外包。

商业模式

开源 skills（MIT），官网 gtmcofounder.com 独立存在。

判断

这个产品在做一件很难的事：把"判断力"打包成"工具"。

GTM 的本质是一连串没有标准答案的判断——这个功能对谁重要、值多少钱、 先打哪个渠道。它不是流程问题，是认知问题。把它做成 skill，等于假设 "好的提问顺序能替代经验"。这个假设可能只对了一半。

可迁移的规律：情感切入的精准度，可以在冷启动阶段替代产品成熟度。 它能拿下单日榜首，靠的多半不是功能有多强，而是那句"尤其是给你的" 击中了一群人。这是营销的胜利，不是产品的胜利——但在早期，这一样算数。

代价是这类产品的留存会很难看。情感共鸣带来下载，但解决不了"我这个具体情况怎么办"。 一旦用户发现它给的是通用框架而不是针对性判断，就会流失。

下一步看什么

  1. 官网到底卖什么 —— 免费 skill 之后有没有付费的东西，这决定它是生意还是作品
  2. 三个月后 star 还在不在涨 —— 单日榜首带来的是脉冲流量，看得出留存的只有曲线形状
  3. 有没有用户案例 —— 有人靠它真的做出了 GTM 决策并成了，才算证明假设

对你的可迁移点

这个产品是你的反面，所以特别值得看。 它试图把你二十年积累的那种判断力 打包成软件卖给不懂营销的人。

  • 它做得到的部分：提问的顺序、该看哪些指标、常见陷阱清单——这些确实能标准化
  • 它做不到的部分：具体情况下选哪条路。而那恰恰是客户真正付钱买的

这个边界对你有直接价值：如果你要把自己的方法论产品化（不管是做工具还是做课）， 这条线就是你的定价分界线——能标准化的部分免费送，做判断的部分才是收费的。

话术：直接看它的开场白。它没有说"我们提供 GTM 解决方案"， 它说的是"有些日子就是单纯地难熬"。这是你写文案时一直在用的东西， 但在 To 开发者的产品里极少见——所以它赢了。

结论

值得关注。 产品本身可能撑不了太久，但它划出的那条"能标准化 vs 要判断"的边界， 对你把经验产品化这件事有直接参考价值。
