1. shuohao-skills（烁皓）· 开源关注 655 · 强烈推荐

把一本小说拆成能直接开拍的短剧素材包：角色设定、形象提示词、音色、分集大纲。

替代的旧行为极明确——编剧写人物小传、美术出设定图、导演排分集，一个团队三五人做一两周。

为什么值得看：所有人都在卷"AI 生成视频画面"，它绕到上游做"开拍前的素材准备"。 这一段最耗人、最依赖经验，也最没人愿意做成产品，因为演示效果差。 它和你的 songo 重合度极高，而且它的 13 道质量门（把创作质量变成脚本能检查的硬约束） 这个思路可以直接搬。

变现走的是开源引流 + 付费微信群，天花板低，但路径已经跑通。

2. 影策 open-ai-canvas · 开源关注 535 · 强烈推荐（但先查域名）

一张画布装下整部戏：从小说抽角色资产，再把分镜、图、视频、音频编排成片。

几乎就是 songo 的开源版本。 它赌的是"容器"而不是"生成"——不做任何生成模型， 只做把生成结果组织起来的那张画布。底层逻辑是：模型能力会趋同，最后拼的是谁掌握创作的组织结构。

去读它的角色资产数据结构——怎么定义一个角色的"外观、声音、气质"并让这些 在不同生成环节间保持一致，这是 songo 最难的部分，现在有人把答案写在 GitHub 上了。

⚠️ 一个疑点：项目 homepage 填的是 ddcat.pronhubcn.com，域名形态可疑。 查清楚之前别往那上面传素材。

3. The GTM Co-Founder · 开源关注 176 · 值得关注

给没有合伙人的技术创始人当营销脑子。

它是你的反面，所以特别值得看——它试图把你二十年积累的那种判断力打包成软件， 卖给不懂营销的人。它做得到的是提问顺序、指标清单、陷阱列表；做不到的是"我这个具体情况选哪条路"。

这条边界对你有直接价值：如果你要把自己的方法论产品化， 这就是定价分界线——能标准化的部分免费送，做判断的部分才收费。

另外看它的开场白：不说"我们提供 GTM 解决方案"，而说"有些日子就是单纯地难熬"。 它能拿下产品社区的单日榜首靠的是这个，不是功能。

今天的趋势：SaaS 正在被为 agent 重做一遍

不是猜测，是今天一天里同时出现的东西：

产品 是什么

mcp-server 给 agent 一个能打电话的电话号码

CRM 有了、搜索有了、沙箱有了、记忆有了、可观测性有了，连"给 agent 一个电话号码"都有了。

这意味着什么：现在的钱在流向"卖给 agent 的工具"，不是"卖给人的应用"。 对你的判断价值是——如果你要做面向人的 AI 产品，这一波拥挤跟你无关， 反而说明"给人用的那一端"正被相对忽视。
