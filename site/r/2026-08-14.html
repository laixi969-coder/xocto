AI 应用雷达 · 2026-08-14

5 个

今天几乎所有候选都围绕 DeepSeek Harness 展开，插件生态呈现爆发态势。给人用的那一端依然稀缺。

01

deepseek-harness

DeepSeek 官方插件化框架，GitHub 7.3万星。"一切皆插件"的理念正在催生庞大生态，值得关注其标准化方向。

02

dsh-tui

Claude Code 风格全屏交互终端插件，571星，解决官方无 TUI 痛点。CLI 极客的补位之作，说明工具链体验分层正在细化。

03

dsh-workflow

把一次性多 Agent 调度升级为可生成、可保存、可治理的 Workflow 层。从一次性到可治理，是 agent 工程化的关键一步。

04

  • dsh-agent-teams：多 agent 团队协作插件，168星。
  • dsh-better-sidebar：侧边栏完整工作台，453星。
  • dsh-genui：对话内联渲染交互式 UI 组件。
  • dsh-tianshu-tui：终端 UI 插件，内置 TDD 与证据门。
  • dsh-vision-toolkit：DSH 原生视觉插件，253星。
  • dsh-web-ui：Web UI 插件和皮肤集合，1086星。
  • phi：带权限门的编码 agent。
  • promentor：AI 编程导师技能。
