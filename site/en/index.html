01

Merge

Not a business yet
What it is

Hiring engineers no longer means handwritten algorithm puzzles. Candidates review a change like they would at work, and the machine scores them.

How it makes money

Pricing not disclosed; the website only offers "book a demo."

Where to enter

After assistants can write code, hiring still tests handwriting — the exam no longer matches the job. The trend is assessing judgment, not output. The entry is code review in technical hiring, sold to the hiring side. Public pricing is not out.
