01

Deepgram

First discovery

2026-10-20 · AI transformation · Call centres and customer service / Healthcare / Media and content

What it is

When contact-centre QA, hospital transcription and media subtitle teams need to turn large volumes of recordings into text and analysis, they send audio to Deepgram's speech-to-text and voice-agent models, which return transcripts, call analysis and spoken replies; the new fact is that these offline batch jobs can run on AWS Trainium2 with eight model replicas per instance, while delivery quality and human review steps remain to be verified.

Why it matters in this edition

Trend: speech transcription is moving from per-minute cloud APIs to batch infrastructure that can be self-hosted and cost-tuned, so inference efficiency decides how many audio hours a fixed budget buys. Entry: avoid a generic transcription API and start from a compliance-heavy step such as contact-centre QA or medical transcription, charging per processed hour or per QA report, with domain vocabularies, de-identification and human review as the moat.

vLLM introduced push-based KV cache transfer for disaggregated inference, moving KV blocks directly between GPU or Trainium device memory over AWS EFA RDMA via the NIXL connector to cut prefill-to-decode transfer overhead. The optimization targets time-to-first-token and time-per-output-token; if it holds up, it would lower latency and resource use for long-context inference, directly affecting serving cost and throughput, though the material does not quantify the gains (inference).
