Why this would be needed

Use case

When a designer receives a UI, infographic or poster brief, they feed a text description to the model to produce a layout-appropriate image draft, then manually refine details before review.

The public material does not state the current alternative; by common practice it may be generic text-to-image models plus manual layout, but this is inference unsupported by the material.

The public material offers only a one-line model positioning and does not show where designers currently get stuck, how many rework rounds occur, or how long it takes, so the pain cannot be reconstructed from public facts.

Problem identified, demand strength unclear
