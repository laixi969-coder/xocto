01

Why this would be needed

Start inside the user's day · Public facts + commercial validation · 2026-09-19

Use case

An individual knowledge worker answering a specific question across material scattered in several note and document tools needs to locate the relevant passages quickly and know which section the answer came from, so they can judge whether to rely on it.

Manual search across several note apps, pasting whole documents into a general chat model, or hand-rolling a vector retrieval script.

The old way is repeated keyword search across several tools or pasting whole documents into a general chat model; the former misses content that appears in only one section, the latter gives no traceable source, so the user still has to go back to the original text to verify.

xOcto's call

Demand is evidenced

The trend is that private personal and team corpora are being turned into a retrieval layer that AI agents can call, rather than being stuffed into one large model. A wedge is document-heavy small teams such as law, audit or consulting that must show sources: sell the cited answer as the deliverable, not seats. Pricing is undisclosed and not assumed.

Reason to use it

Why users would choose it

Inference: compared with pasting whole documents into a chat model, it first narrows the scope to sections via hybrid vector plus BM25 retrieval and then returns section-level cited answers, removing the step where the user hunts for and verifies each source; so individuals or small teams that need citations but do not want to build retrieval themselves would try it first when writing or researching.
