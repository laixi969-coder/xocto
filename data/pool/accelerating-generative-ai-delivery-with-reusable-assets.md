# Accelerating generative AI delivery with reusable assets

If you’re building generative AI solutions, reusable assets can help you stop rebuilding components that already exist: Retrieval Augmented Generation (RAG) pipelines, document processors, agent scaffolding, and so on. This has a compounding cost: time not spent solving the customer’s actual problem. This post shows you how to access a curated catalog of 23 production-ready assets from the AWS Generative AI Innovation Center, now part of AWS Frontier AI Engineering & Services. These assets can reduce your development time from months to weeks, with evidence from companies like DoorDash , Lyft , and Ricoh . Since 2023, the AWS Generative AI Innovation Center has published open source reusable assets. These production-grade building blocks give you a validated foundation to start from instead of a blank file. These assets have powered customer solutions delivering measurable results: 50x increases in testing capacity, 90 percent reductions in engineering hours, and deployment timelines compressed from months to weeks. In this post, you will learn why teams keep rebuilding generative AI components, what makes an asset truly reusable, how companies like DoorDash and Ricoh achieved measurable results by using these assets, and how to access and deploy 23 open source assets from the catalog.
