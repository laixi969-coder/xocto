# From learning to leaderboard: How Cisco upskilled 1,200 engineers in agentic AI with AWS AI League

Cisco, like many large engineering organizations, is adopting generative and agentic AI to change how its engineers build software. The hard part is no longer access to the technology. It’s helping thousands of engineers move from watching a demo to confidently building with it. Recorded sessions and slide decks rarely close that gap. Engineers learn fastest when they build something real, see it fail, fix it, and try again. AWS designed AWS AI League for exactly that. It turns hands-on AI learning into a gamified competition, where participants customize models and build agents on AWS, get instant feedback on a live leaderboard, and compete in a game-show-style finale. Cisco is one of the clearest examples of what this looks like at scale. In 2025, Hemanth V, a Cisco software engineer, went from an internal Cisco event to being crowned the first AWS AI League Champion at AWS re:Invent 2025. In 2026, 1,200 Cisco engineers competed in an AWS AI League tournament at Cisco Transformation Fest 4.0. The winner, Nishanth Aluhonnu, earned a full event pass to AWS re:Invent 2026 in Las Vegas.
