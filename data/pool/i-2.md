# I

把之前做的工具整理了下， 直接 npm install -g livesub && livesub 就可以使用，内置本地模型的管理，模型推理部分只依赖 cpu, 稍微新一点的电脑就可以跑。

ASR 和 翻译部分可以分开选择的。qwen-asr + firefox translate 是集成好的纯本地方案，在 UI 里下载模型就能用。

我自己一般是选择本地的 ASR + deepseek 翻译来综合隐私速度和准确率。


https://i.imgur.com/92aXKUr.png
https://i.imgur.com/fAjkCIP.png

ASR 除了本地的 qwen3-asr 还支持阿里百炼的 qwen 和 openai
翻译除了本地的 firefox translate 还支持 openai/claude/deepseek. (LLM 除了翻译还能顺带纠错会比较好用）

目前自用就偷懒只做了 webui, 靠 PWA 和 chrome 的画中画来运行，等有人用再改桌面端:)
