# Openi

# 体验社区链接

> 体验网址： https://openi.pcl.ac.cn/

## 一、背景

偶然小组有人分享了 OpenI 启智社区，看上去好像是一个免费算力的学习网站，固小小的体验了一下。

## 二、核心功能

| 功能 | 说明 |
|------|------|
| 📦 代码托管 | 类 Git 仓库，支持协同开发 |
| 🗂 数据集 | 数据集上传、管理与共享 |
| 🧠 模型 | 模型的上传、下载与管理 |
| ⚡ 云脑算力 | 调试、训练、推理任务，支持 GPU / NPU |

## 三、我觉得值得关注的点

1. **算力门槛低**：平台提供免费的 GPU/NPU 算力，对没有服务器的学生和个人开发者比较友好。
2. **国产算力适配**：除英伟达 GPU 外，还支持华为昇腾 NPU 等国产算力。
3. **开源模型资源**：社区上线了很多不错的模型，也在春节期间上线了 DeepSeek 系列模型，可以直接验证和测试。
4.  **新手教程多**：有“小白操作指南”和用户经验贴，上手比较容易。

## 四、适合谁用？

- 没有 GPU 的学生、科研人员
- 想体验国产 NPU/昇思 MindSpore 的开发者
- 想找开源数据集、模型的 AI 爱好者

## 五、使用小提示

- 算力和队列资源以平台实际页面为准，高峰期可能需要排队。

## 六、总结

手写：体验下来，能够跑一些参数不大的轻量模型，里面也有写 A100 和 C500 的卡可以用，也还不错。做 AI 视频和日常推理，如果不是很复杂的，学术或者简单用完全没有问题，还是那个老问题，算力的规模不够大，但是玩玩体验下本地部署模型完全可以的




体验评分：⭐⭐⭐⭐
