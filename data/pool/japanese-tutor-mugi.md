# japanese-tutor-mugi

倉鼠むぎ陪你一對一練日語會話的手機網頁 App。核心思想：讓 LLM 以 JSON Schema 輸出結構化回覆，日文台詞與中文小提醒分欄位，前端用部分 JSON 解析邊收邊顯示；長時間聊天也維持 prompt 快取與語音快取。漢字讀音由 LLM 標註，漏標的由伺服器端 kuromoji 補上。糾錯自動存成小提醒本，可以開口練到會。語音可選本機 VOICEVOX 或雲端 Google／Azure，金鑰只留在本機伺服器。以 Claude Code（Opus 5.5）協作開發，原為個人使用，以不含個人資料與第三方素材的全新 git 歷史開源發布，各項決策紀錄見 docs/decisions/。
