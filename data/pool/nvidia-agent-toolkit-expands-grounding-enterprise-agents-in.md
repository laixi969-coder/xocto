# NVIDIA Agent Toolkit Expands, Grounding Enterprise Agents in Company Data

Agents are only as useful as what they know, and only as trustworthy as the boundaries they run within. Leading enterprises are using the open source NVIDIA Agent Toolkit — now expanded with new tools — to customize and control agents, use company data to inform their answers and actions, monitor what they do and govern how they operate. NVIDIA Agent Toolkit comprises: The new NVIDIA Agent Knowledge Foundation with NVIDIA CUDA-X libraries NVIDIA open models including Nemotron Retriever and the new Kumo family NVIDIA OpenShell secure agent runtime NVIDIA NemoClaw secure agent blueprints Tools and skills, like NeMo Relay and NeMo Compass Read All NVIDIA in Europe Announcements To develop agents that accomplish real work and are trustworthy from development to deployment, builders need an open agent stack that brings together the models, harness, runtime, data and tools. NVIDIA Agent Knowledge Foundation helps enterprises turn data into company intelligence agents can use. Agents can find relevant information, understand what it means for the business and use it to make predictions and help people decide what to do next. Companies can use Agent Knowledge Foundation without moving data, rebuilding existing workflows or changing governance controls. The foundation features NVIDIA CUDA-X
