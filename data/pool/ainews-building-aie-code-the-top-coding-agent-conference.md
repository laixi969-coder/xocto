# [AINews] Building AIE CODE: The top Coding Agent Conference

It’s a quiet day, so as we have done once per conference, we’ll do a behind the scenes look at AI Engineer , now serving 6M views a month for 1.8M monthly unique viewers . CODE is the last flagship AIE of the year (there are also 2 partner conferences coming up - AIEi Shanghai takes place next week, and AIEi Sydney is a side event of NeurIPS in December). As a Summit it is meant to be more intimate: single track, invite-only for the top 1000 agentic engineers in the world (over 100k tuned into our Software Factories track at WF26 ). My goal in curating AIE CODE is to try to recap the top themes of 2026 in code and gather the leaders of the industry to preview what’s next in 2027. Last year we had some absolute bangers building Skills and Software Factories , predicting the death of the IDE and of course the launch of Antigravity and Nano Banana Pro. We have three themes this year: Scaling without Slop : Last year’s call for No More Slop has resulted in lots of discussions about managing it this year, including the rise and fall of Tokenmaxxing .
