# PolyAI Dialog-RSN-1 is now on Amazon SageMaker JumpStart

Dialog-RSN-1, a reasoning model built for real-time complex dialog, is available today on AWS Marketplace and Amazon SageMaker JumpStart. It powers frontier dialog: agents that hear a live call, reason about it, and act in real time. As an AWS customer, you can subscribe to Dialog-RSN-1 through AWS Marketplace and deploy it as a SageMaker endpoint inside your own AWS environment. You can also deploy directly from Amazon SageMaker Studio following the steps in Deploy and evaluate models with Amazon SageMaker JumpStart . That means the model designed to handle your customer conversations can be deployed like other Amazon SageMaker models with an AWS Marketplace subscription. Deploying Dialog-RSN-1 inside AWS Dialog-RSN-1 is the first PolyAI model available through AWS Marketplace . It runs inside your own AWS environment on the same AWS cloud that powers PolyAI’s compute and model training and serving. All in a single pass, Dialog-RSN-1 perceives a caller’s audio directly, reasons about what they need, and responds in real time. On SageMaker, it deploys as an endpoint like other models you run there.
