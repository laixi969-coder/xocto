# Github

一直用习惯了 Jetbrains IDE 的 git 管理，现在因为 AI 编程逐渐转向了 VS Code ，但是感觉自带的 git 功能不好用，这两天用 opus 基于开源的 Rebased 客户端，复刻做成插件。

实现了一下能力
- 带提交图的 Git 日志；
- Commit 工具窗口（ changelist 、Shelf 、Stash 、Branches ）；
- 三栏合并窗口和交互式 Rebase ；
- Local History ；
- Push 、Update 、Merge 、Rebase 等 Jetbrains 对话框。

插件地址： https://github.com/PGshen/vs-idea-gittool/releases/
