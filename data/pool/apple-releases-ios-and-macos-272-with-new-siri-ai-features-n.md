# Apple releases iOS and macOS 27.2 with new Siri AI features, new Music logo

Today, Apple rolled out the 27.2 updates for its operating systems, including iOS, macOS, watchOS, tvOS, visionOS, and so on. Let's start with iOS 27.2. This update is heavily focused on Siri AI. It adds a memory feature to Siri, so it can "recall your past conversations" and reference them when chatting with you.
