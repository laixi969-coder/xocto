# Workflow context for AI agents with Smartsheet MCP on AWS

AI agents are most useful when they can act on the real work happening across your organization. Running projects and operations involves complex, cross-functional tasks such as updating project timelines, reassigning tasks, and surfacing status. AI agents can support you with these without anyone switching tools. Smartsheet has launched a generally available Model Context Protocol (MCP) Server. With the Smartsheet MCP Server , AI assistants can read, write, and manage Smartsheet data through a standardized protocol. The protocol spans more than 40 tools for exploring, creating, and managing sheets, rows, columns, and automations. You can update task statuses, create rows, and modify project structure directly through natural language. In this post, we walk through two ways you can connect it to your existing workflows. Amazon Quick is an agentic AI workspace built for business users, project managers, and operations teams. They can ask questions, update sheets, and build dashboards through natural language without writing code. Kiro is an agentic IDE where developers connect to Smartsheet through MCP to reference project specs, update task status, and track dependencies without leaving their coding workflow.
