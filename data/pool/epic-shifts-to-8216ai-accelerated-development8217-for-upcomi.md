# Epic shifts to &#8216;AI-accelerated development&#8217; for upcoming Disney game

Epic Games plans to use AI to generate code and art for an unannounced Disney game, which is now delayed from its original March release window, according to a report from Bloomberg . The project's developers have been given an "AI-first" mandate directing them to use tools like Anthropic's Claude more to finish the game. According to Bloomberg , one of the game's directors said in a message to staff, "No more hand-written code." Staff were also told that all of the game's art will be "generated with full AI workflows."
