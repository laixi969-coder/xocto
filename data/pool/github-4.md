# Github

# 每天在十几个终端窗口里切来切去？我做了一个本地 Coding Agent 工作台：CoDock

做日常开发时，大家应该也慢慢习惯了让各种 AI Agent 帮着写代码：
- A 项目用 Claude Code 跑架构重构；
- B 项目用 Codex 改改小 bug ；
- 偶尔还想切到 DeepSeek Harness 或 Gemini CLI 跑跑对比测试……

不知不觉，电脑任务栏里就堆了七八个黑乎乎的终端窗口。
每次切窗口都在找「刚刚那个任务跑在哪个终端里？」「跑完了没有？」「上周聊过的那个思路在哪条会话里？」
在命令行里敲一段稍微长一点、带多行格式的 Prompt 更是折磨。

为了解决自己每天遇到的这些痛点，我开发了 **CoDock** —— 一个专为 Coding Agent 打造的本地桌面工作台与终端控制中心。

---

### 🌟 核心想解决的几个问题

#### 1. 告别杂乱黑窗口，聚合 9+ 主流 Coding Agent
在一个统一的高性能桌面窗口里多 Tab 并行运行：
**Claude Code · Codex · DeepSeek (dsh) · Gemini CLI · Antigravity (agy) · Grok · Pi · Opencode · CodeBuddy · Cline**
随时切 Tab ，支持重命名、项目分组、自定义 Agent 排序和一键呼出。

#### 2. 任务到底跑完没有？智能提醒与任务栏闪烁
把长任务丢给 Agent 之后，通常需要切走去写别的代码或接杯水。
CoDock 能够智能识别 Agent 的运行状态（处理中、静默完成、等待用户交互确认）。当 Agent 跑完或等待你确认时，对应 Tab 会亮起小圆点，桌面任务栏联动闪烁提醒，不再需要来回切窗口干等。

#### 3. 终于能看懂我的 Token 到底花在哪了
各个 CLI 各自为政，月底根本算不清账。
CoDock 本地直读各 Agent 的原生日志与 SQLite 数据（**绝不上传任何云端**），自动按天、按项目、按模型聚合成用量趋势图与 Token 消耗看板。

#### 4. 独立的 Markdown Composer：舒服地写长 Prompt
在黑窗口里改 Prompt 、打换行极为痛苦。CoDock 提供了一个全局独立的 Markdown Composer 浮窗：
- 结构化排版、长文本多行编辑、常用模板库；
- 还可一键接入大模型对提示词进行优化与 diff 差异对比；
- 写好后一键精准投递到当前活跃终端。

#### 5. 躺在沙发上、手机也能看进度
支持自适应手机/平板端界面，离开电脑去泡咖啡或开会，手机连上局域网就能随时查看输出流、应急输入快捷键；还支持将单个会话生成受控的局域网分享链接给同事看。

#### 6. 纯本地运行，数据隐私安全
完全基于本机 PTY 启动各 Agent CLI ，数据 100% 保留在你自己的磁盘上（`~/.codock/`），无任何第三方服务器中转。

---

### 🚀 立即体验与下载

目前已提供各操作系统的预编译安装包与二进制，下载解压或双击安装即可直接使用：

- 📥 **官方发布仓库**： https://github.com/juejijianghuaa/CoDock-Release/releases/latest
  - **Windows**：提供安装程序 `CoDock-Setup-x64.exe`（支持关闭到托盘与资源管理器右键启动）以及免安装便携版
  - **macOS**：提供 Apple Silicon (M1~M4) 与 Intel 架构的双 DMG 安装包
  - **Linux**：提供独立二进制，支持桌面 GUI 与纯 Server 模式

欢迎大家下载体验！如果有任何使用建议或遇到了 bug ，非常欢迎在 GitHub Issue 或帖子里留言交流，如果觉得对你的日常 Coding 有帮助，也欢迎给发布仓点个 ⭐️ Star 支持一下！
