# Ip

很多轮子大家都是看到过 现在手搓直接开源 让大家也可以用自己的轮子



* 🌐 **在线体验**：[https://ip.huzhihui.com]( https://ip.huzhihui.com)
* 📦 **开源仓库**：[https://github.com/zhihui-hu/one-ip]( https://github.com/zhihui-hu/one-ip)（如果觉得顺手，求个 Star ⭐️）

---
目前主要能做这些事：
- 看出口和分流：分别探测国内、外部 IPv4 ，再看不同网站实际使用哪个出口。
- 查 IP 信息：归属地、运营商、ASN 、企业类型、住宅/机房标记、信誉分，以及更详细的网络信息。
- 排查连通性：网站 HTTP 响应耗时、全球 Ping 、DNS 出口、CDN 节点。
- 检查浏览器：指纹、环境一致性、自动化特征、WebRTC 和权限信息。
- 看 AI 平台访问情况：接入了 ChatGPT 、Claude 、Gemini 、DeepSeek 等八个平台的访问探测。
- 查看服务状态：集中查看 Cloudflare 、GitHub 、OpenAI 、Claude 、Vercel 等服务的官方故障和维护信息。
