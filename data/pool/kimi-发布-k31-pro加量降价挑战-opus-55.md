# Kimi 发布 K3.1 Pro，加量降价挑战 Opus 5.5

作者｜宇航猿 编辑｜靖宇 10 月 23 日上午，Kimi 官方在 X 和视频号上发了一段 24 秒的视频。 画面里是一台复古风格的老式电脑，屏幕上开着 Kimi Code，终端里一行行地写着 Three.js 代码，在生成一个复杂的 3D 场景。眼尖的网友很快在左上角的模型栏里找到了答案——「Model: Kimi K3.1」。 Kimi 官方发布的 K3.1 预热视频｜图片来源：X @Kimi_Moonshot 用一台老古董般的机器，跑一段今天最前沿的 3D 代码，这个反差本身就是月之暗面想说的话。 十几个小时后，10 月 24 日零点刚过，卡着程序员节，Kimi K3.1 Pro 正式上线，同步推出的还有一个速度快 2 到 3 倍的 Highspeed 版本。官方承诺，完整模型权重将在 11 月 4 日前放出。 距离上一代 K3 发布，过去了三个多月。这三个月里，月之暗面经历的事情，比大多数公司一年还多。 01 「加量不加价」的 0.1 先说清楚 K3.1 Pro 是什么。 它不是一个全新的模型。月之暗面明确表示，K3.1 Pro 是 K3 的后训练版本，底座没换——仍然是 2.8 万亿总参数、1040 亿激活参数的混合专家架构，仍然是 100 万 token 的上下文窗口，仍然原生支持图像和视频输入。 变的是后训练。官方的说法是投入了「大幅增加的后训练算力」，在数百个下游领域做了大规模联合强化学习，为此把强化学习框架、沙箱基础设施、长上下文推理这些底层工程都重构了一遍。 也就是时候，同一个大脑，被重新「教」了一遍怎么干活。 效果体现在榜单上。在考察编程智能体的 Terminal-Bench 4.0 上，K3.1 Pro 拿到 65.7%，超过 GPT-6 Astra 的 58.2%，和 Claude Opus 5.5 的 66.4% 只差不到一个点。上一代 K3 在这个榜单上的成绩，按第三方机构 Artificial Analysis 的测法只有 13%。 第三方的综合评分也给了面子。 Artificial Analysis 智能指数上，K3.1 Pro 拿到 55 分，比 K3 高出 11 分，排名全球第四，前面只有 Claude Opus 5.5、Claude Sonnet 5.5 和 Muse Wonder Full 。等权重正式放出，它将成为得分最高的开放权重模型，开源与闭源之间的差距会从 12 分缩小到 3 分。 K3.1 Pro 在 14 项编程、科学与知识工作评测上的表现｜图片来源：Kimi 官方博客 除了编程，这次的两条新主线是 3D 和金融。 K3.1 Pro 能驱动 Unity、Unreal、Godot 这样的游戏引擎，能写 Blender 和 CAD 脚本做参数化建模。在从多视角图片重建 3D 模型的 BenchCAD 测试里，它借助工具拿到 92.7%，接近 Opus 5.5 和 Astra。Kimi 网页版和 App 也同步上线了「3D Make」，可以直接描述需求，生成 3D 网页、3D 模型，甚至导出给 3D 打印机。 kimi.com 上的 3D Make 界面｜图片来源：Kimi 官方博客 回头再看那段预热视频，老电脑屏幕上跑的 Three.js，其实就是在给这条主线打预告。 金融方面，K3.1 Pro 在基于真实财报做多步数值推理的 OfficeQA Pro v2 上拿到 64.4 分，官方称是目前最好成绩。在官方自己设计的高难度幻觉测试里，事实性错误率从 K3 的 23.4% 降到了 8.3%——当然，这是一个刻意找茬的压力测试，不代表日常使用的错误率。 金融类评测成绩｜图片来源：Kimi 官方博客 最让人意外的是价格。 K3.1 Pro 的 API 定价是每百万 token 输入 13 元、输出 68 元，比 K3 便宜了三分之一，大约是 Claude Opus 5.5 的一半。 更强的新模型反而比旧模型便宜，这在大模型行业并不常见。 不过 Artificial Analysis
