# 飞行汽车登上 Web Summit 主舞台, 中国科技公司在欧洲讲了一个什么故事?

11 月 9 日晚, 里斯本。近两万人的体育场里，一位中国创始人用中文讲起了飞行汽车。 这是 Web Summit 开幕式的主舞台。台上的人是小鹏汇天创始人赵德力, 舞台两侧停着他带来的产品:分体式飞行汽车「陆地航母」的陆行体和飞行器。据小鹏汇天介绍, 这是首个登上 Web Summit 主舞台的飞行汽车企业。 比产品本身更值得注意的, 是这次出场的方式:中文演讲, 主舞台, 面对全球创业者、投资人和监管从业者。 一场不太一样的「出海」 Web Summit 创立于 2009 年, 常被称为「科技界的奥林匹克」。马斯克、微软总裁布拉德·史密斯、英国前首相布莱尔都在这里演讲过。今年的参会者来自 150 多个国家和地区, 超过 7 万人,2000 多家媒体到场。 对创业公司来说, 这里是找钱、找合作、找话语权的地方。 今年的中国面孔格外多:小米、腾讯、稀宇科技、智元机器人、宇树科技、银河通用、优必选都在里斯本。开幕式入场环节, 各国代表手持国旗进场, 走在最前面的是中国和东道主葡萄牙。 官方的说法是, 中国企业正在「从走出去到扛大旗」。这个表述有宣传味, 但背后的变化是真实的。早期出海, 卖的是产品, 比的是性价比和渠道。现在的出海, 开始争的是赛道规则、技术路线和叙事权。 另一个信号来自主办方。据稿件披露,Web Summit 正在布局东亚, 计划在中国内地落地相关峰会活动。顶级科技会议开始「向东看」, 也说明中国企业在前沿赛道上已经是它绕不开的一方。 陆地航母：先解决「飞行汽车怎么用」 飞行汽车喊了很多年, 卡住的往往不是飞起来, 而是飞完以后:飞行器放哪、怎么挪、怎么充能。小鹏汇天把这三件事概括为「移动难、停放难、补能难」,「陆地航母」就是对着它们设计的。 核心思路是分体:一台车加一台飞行器。 两部分靠车载自动分合机构连接, 约 5 分钟即可完成自动分离与结合。陆行体采用三轴六轮六驱布局, 搭载 800V 碳化硅增程动力,CLTC 综合续航超过 1000 公里。飞行体用「四轴合一」的单杆操纵方式, 目的是降低驾驶门槛。使用场景上, 它既能满足个人娱乐飞行, 也能用于应急救援、巡逻巡检等公共服务。 这条路线的逻辑是, 地面部分负责解决路上的问题, 飞行器只在需要的时候升空。它不是让一台机器同时做好两件事, 而是让两台机器配合。至于 5 分钟分合在真实场景里的稳定性和成本, 还有待量产后验证。 同场介绍的另一款产品 A868, 是高速、长航程的全倾转机型, 瞄准城市之间、交通枢纽之间的跨区域出行。 两条产品线, 对应赵德力对未来十年的判断:低空出行会沿两个方向推进。传统航空会向智能化、电动化、便捷化发展, 而新时代的汽车最终会进化出「翅膀」进入天空。 卖产品之外, 还要卖一套方案 这次演讲里, 小鹏汇天强调的不只是产品, 还有「低空飞行解决方案」。 据介绍, 他们此前已与阿联酋签署战略合作协议, 共建国家级先进空中交通监管沙盒, 并计划逐步在中东、东南亚开展试点, 之后再推进欧美市场准入。 这个顺序值得留意:先监管, 再市场。飞行汽车的难点不只在技术, 更在空域、适航和运营规则。能先和地方政府在沙盒里跑通规则, 比单纯卖出几台车更有长期价值。反过来看, 欧美准入目前只是「未来将推进」, 离落地还有距离。 这一晚的意义, 在于一家中国飞行汽车公司, 第一次在全球最密集的科技视线下, 用自己的语言讲了自己的方案。 接下来要看的, 是它能不能把舞台上的演示, 变成路上和天上的日常。
