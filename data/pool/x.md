# 《财经》Token 套餐价格对比

帖子 https://x.com/mylifcc/status/2095723527282291021

报道原文 https://www.163.com/dy/article/L4ILFQL60519DDOA.html

> 《财经》今年 7 月-8 月订阅了国内外主流 Token 套餐，通过开源智能体框架 OpenCode 重复运行同一项任务（统计谷歌 24 个季度财报中的 10 项财务指标）直至耗尽一周 Token 额度。最终根据周额度估算套餐中实际可用的月额度，并计算 1 亿 Token 均价。

如果只看按量付费的价格，中国的大模型确实便宜；但是如果对比各家的 Token 套餐，结论是国内平台的 Token 单价反而更贵。

这里的前提是将额度全部干光。

那为什么说国内套餐更贵呢？

区别首先是额度本身差别巨大。阿里云 499 套餐烧 Qwen3.8-Max 周额度竟然只有 115M Token 。而 Codex 1360 元套餐烧 GPT-5.6 Sol 周额度能有 2543M Token ，这导致阿里云套餐的单 Token 价格是 Codex 的八倍。另外 Kimi 的 699 套餐用来烧 K3 模型，周额度也只有 169M 。

其次是缓存命中率，阿里云套餐在测试中，缓存命中率竟然不到 90%，而 Codex 在 95% 以上，未命中 Token 的额度消耗一般都是命中的十几倍。

最后是输出占比，阿里云套餐是 2.4%，Codex 是 0.2%。这是衡量大模型效率的主要指标，输出占比越高意味着额度消耗越快。

最后一圈比下来，国内套餐的 Token 单价全都比美国贵，只有 DeepSeek-V4-Flash 的按量付费价格是最低的。
