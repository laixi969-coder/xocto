# All Systems Go: Global PC App Ecosystem Ready for NVIDIA RTX Spark

NVIDIA RTX Spark is a new beginning for the PC — a reinvention combining the capabilities of a gaming PC, a creative studio and a personal AI supercomputer into a single superchip. With up to 128GB of unified memory and 1 petaflop of AI compute, RTX Spark delivers the full stack of NVIDIA RTX and CUDA technologies for creators, developers and gamers, while unlocking a new paradigm in personal computing via powerful local AI agents. Last week, NVIDIA and Microsoft announced that RTX Spark laptops will be available on Friday, Oct. 16 . Ahead of the launch, NVIDIA and its ecosystem partners are rolling out new software features and performance optimizations to expand what’s possible with local AI on RTX Spark. New and upcoming RTX Spark updates — among the thousands of apps, games and models available at launch — include: New agent features, models and tools that enhance local agents on RTX Spark: Updates to top agent apps including GitHub Copilot, Hermes, OpenClaw, Perplexity, Pi and WorkBuddy streamline setup on RTX Spark, improve security with OpenShell and Microsoft Execution Containers (MXC), and enable hybrid local and cloud AI routing.
