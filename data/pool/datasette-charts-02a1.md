# datasette-charts 0.2a1

Release: datasette-charts 0.2a1 Minor UI improvements: Collapsing the suggested charts section now leaves the chart visible. Following a link to a chart opens it with the suggestions collapsed for that visit. On table pages the panel now sits below the "4,235 rows where country = CHN" line. The "Data" table under each chart has been replaced by Copy TSV and Copy CSV buttons. Removed the "Chart this data" item from the table, view and query action menus. More space between lines in chart tooltips. Tags: datasette , visualization , datasette-charts
