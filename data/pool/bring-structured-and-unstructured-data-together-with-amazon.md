# Bring structured and unstructured data together with Amazon Quick

Organizations collect data in many forms. Structured data lives in databases and spreadsheets, whereas unstructured data sits in documents, reports, and files stored across file systems. Analyzing both together typically requires switching between multiple tools, running separate queries, and manually correlating results. Amazon Quick addresses this with a unified experience. You can connect structured data through enriched datasets and unstructured data through S3-backed knowledge bases . You can then query both through a single conversational AI agent. In this post, you learn how to: Connect Amazon Simple Storage Service (Amazon S3) as a data source and create a knowledge base. Build a Space that combines structured and unstructured data. Create and configure a custom chat agent that queries across both data types. Ask questions that span structured and unstructured sources in a single conversation.
