# aiconnect

AI Connect is the open source SDK of TensorPass for websites. Add an AI chat, a search bar that answers or an AI mode that runs on each visitor's own ChatGPT, Claude, Gemini or OpenRouter account through the AI Wallet browser extension. It works with React, Web Components, MCP tools and the OpenAI, Anthropic and Vercel AI SDKs.
