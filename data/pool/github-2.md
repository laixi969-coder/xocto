# LightTrans

主要功能是将中文提示词同时转换为：  
- 忠于原意的英文直译
- 更适合大模型理解的英文 Prompt

目的是减少中英文表达偏差，也降低仅因输入语言而被误判为特定地区用户的风险(你懂的)

开源、轻量，可配置自己的模型 API 。
