# Github

最近家里亲戚的小厂想买个进销存，需求其实很简单，主要是**记一下入库出库，汇总看一下每个月收益**。试了下市面上的，要不就是太贵了功能太多，要不就是用起来感觉不习惯，想定制又负担不起。

我正好最近一直想用 AI 做点东西出来，之前试了好几个方向，都感觉是**程序员自嗨**，没啥意思。借着这个机会，花了两天跟他们对接了一下需求，期望的就是**最简洁轻量，定位家庭小仓**，给以前靠手机记账、本子上记账的那些中年人小厂用，没有太复杂的东西，能让他们方便记一下就行。

一开始本来只打算给他们本地部署一下，**Windows 安装启动就行**。结果越往后做，需求就一点点加上来了：

- 一会儿又想加点**入库订单**、**打印模板**、**委外**啥的
- 后面跟着把**移动端**也做了
- 针对他们不太会操作入库的习惯，还做了点 **AI 相关的功能**

做下来感觉还挺不错。

做着做着我发现，他们这种**两三个人的小厂**其实挺典型的：平时接一些外派的机加工订单，做一下润滑剂、钢管修复这些业务，厂里只有一两个操作工人。市面上那种复杂的生产、入库、原料的整体功能他们根本没有；但他们又想有一个能记账、能直观看到的工具，比手机上记账更清楚。市面上的软件要不不符合他们行业，要不他们也不太知道怎么去用。做到现在，感觉这一块真可以做成一个产品，在这个**比较垂直的赛道**里做点东西出来。

----

对我自己而言，已经**干了 10 年 Java 了**，一直都是干外包、做一些基础的功能，没有真正按照自己的想法做一点东西出来。借助这个机会也就做了这么一个，现在把**基础版开源**了，希望大家能点一下 **Star** 支持一下！

项目地址：`https://github.com/Fawkes-hub/jianzao-erp-community`

---
上面这些话。  用 AI 润色了一下自己想法，在这个社区还是来交流一下。  

AI 时代来临，真的做东西很简单，但是有想法很难。  我一直是 Java 后端，对于前端代码可以说是完全不会，借着这个机会，这一次模型用了 Gemini、ChatGPT、DeepSeek，agent 代码这一块一行都没有写, 发版打包服务器都是让 AI 操作。  自己就是负责对接需求、交流方案，让他们写代码、自测代码闭环流程，然后自己操作浏览器做验，可以说 AI 时代真的是理解需求就能做产品。
