# X

我还在免费维护开源项目，别人已经把在线版和价目表安排上了，看到的时候确实有点懵 😂

我是 Archify 的作者。前阵子在这里分享过 3.0 ，今天聊一件有点意外的事。

最近发现一个叫 archifyi.com 的网站，名字只比 Archify 多一个 i 。它的页脚写着 Built with open-source Archify ，链接到我的仓库；页面提供 3 次免费生成，Pro 标价 $19/月。

先说明白：**这不是我做的，也不是我在收费。**

它在 FAQ 和页脚写了独立运营、不是官方服务。这点我也看到了。让我想出来说一句的，主要是名字和域名太接近，又有收费套餐，怕大家把它当成我做的在线版。

价格和声明的截图放在这条帖子里，大家可以直接核对：
https://x.com/t20000622yy/status/2108207399400300642

## 原版 Archify 是什么？

简单说，就是给 AI Agent 装一个画图技能。描述你想讲清楚的东西，它可以生成架构图、流程图、时序图等可交互的图。成品是独立 HTML ，可以查看细节、追踪路径，也方便发给同事看。

支持 Claude Code 、Codex 、Cursor 等多种 AI Agent ，不必通过上面那个第三方站使用。项目本身开源免费；你所用的模型或 Agent 的费用另算。

- 官网： https://archify.si
- GitHub： https://github.com/tt-a1i/archify

Archify 会继续开源免费。约 8 万 Star 对我来说已经很不真实了，谢谢大家一直帮忙分享、使用和提建议。

也想听听大家的看法：当第三方服务的名字和原项目只差一个字母时，开源作者怎样把官方入口讲清楚，才不容易让用户认错？
