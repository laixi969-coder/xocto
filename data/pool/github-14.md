# Github

做了一个通用的多 agent 协作工具，通用指的是不管在什么 agent 软件里都能用，甚至是像 chatgpt 网页版里的对话也能用。 概念很简单，就是可以创建一个对话房间，然后让你想要协作的 agent 加入到房间里他们就可以随便互相发消息对话了，可以是同一个软件里的 agent ，也可以是不同软件里的，比如让 claude 指挥一堆 gpt 干活；还可以是跨设备的，让一台电脑上的 ai 指挥另一台上面的干活。 项目是开源免费的。https://github.com/rainyflash/agent-room
