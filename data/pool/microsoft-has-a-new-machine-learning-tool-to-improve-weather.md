# Microsoft has a new machine learning tool to improve weather forecasts

Researchers with the company say they've found a new, cost-effective way to make more accurate weather forecasts two to six weeks in advance - allowing farmers and emergency responders to plan ahead with greater certainty. The findings were published today in the journal Nature , and the tool is now open-source software . Microsoft joins Google , Nvidia , and other companies developing AI tools for weather forecasting.
