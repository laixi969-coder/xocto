# ai-desktop-outfit-video

AI 桌面换装视频怎么做？把全网刷屏的「桌面动态壁纸换装」逐帧拆解，整理成一条可直接复制的提示词模板：一条提示词直出 30 秒成片，固定机位一镜到底，中文对白和字幕全部由模型生成，无需后期剪辑。适配即梦、豆包、Seedance 2.5 等 AI 视频工具，附火山方舟 API 脚本，并封装成 Cursor / Claude Code 可一键安装的 Agent Skill：说一句想法，它反过来采访你，自动写出精准提示词。
