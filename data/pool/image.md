# Oh-My-CPA

![social-preview|690x345]( https://image.dooo.ng/c/2026/10/04/6ac275d062acf.png)

仓库地址: https://github.com/WizisCool/oh-my-cpa

Oh-My-CPA 这个项目从 8 月 31 日创建仓库至今已连续开发一个多月，消耗 200+ 亿 Token 。
起初只是为了让自己的 CPA 用着舒服一些，后来有一些佬友感兴趣，于是决定继续优化后开源
感谢开发期间社区的意见和 Bug 报告 :pray:

仓库的 PR 在我一人开发的情况下已经累计合并了 **124 个 PR**，总 Commit 在压缩合并的情况下也已经到达了 **458 条**，是时候正式发布出来，和社区一起集思广益、共同迭代了。

---

## **项目介绍**

[Oh-My-CPA (OMC)]( https://github.com/WizisCool/oh-my-cpa) 是一个 CLIProxyAPI 的前端管理面板，使用 React + AntDesign 进行开发，拥有用量统计，定价，OAuth 管理，API 提供商管理，请求记录与 CPA 运维等功能

在保证官方 CPAMC 的完整体验下，添加了强大的请求记录和统计的功能且还在持续迭代中

另外 OMC 原生支持 MCP ，可以供外部 Agent 接入，并且网页端也提供了**智能体**功能，虽然目前的功能还不完善，但是底层设计的接口很多，是后续更新迭代的主要目标之一
可以在 Web 端使用接入 CPA 的模型直接对 CPA 和 OMC 进行 CRUD 操作
