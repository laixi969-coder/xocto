# 为什么 Anthropic 不做 Personal AI

不久前，9 月 29 日的 OpenAI DevDay 开发者日，舞台上飘出了几个圆滚滚的小气泡。 它们叫 dots，是 OpenAI 最新的个人 agent。每个 dot 跑在 GPT-6 Astra 上，拥有一台独立的云端电脑和浏览器，用户关掉 ChatGPT 之后，它还在后台继续干活。OpenAI 对它的描述是： 「 built to handle everything 」，什么都能接。 三周前的 9 月 8 日， Meta 推出了 Muse，同样有独立的云端虚拟机，同样能在后台持续工作，同样顶着一个萌萌的卡通形象，而且直接住进了 WhatsApp。市场的反馈相当热烈，Apptopia 的估算显示，Muse 上线 12 天全平台装机量约 280 万，一度冲上美区 App Store 总榜第一。 OpenAI CEO Sam Altman 发布个人助理 dots｜图片来源：PCMag 再算上 Google 的 Gemini Spark 和 SpacexAI 的 Grok Bot， 「always-on 个人 agent」成了 2026 年秋天最拥挤的赛道 。 不过，名单里少了一个名字。 Anthropic，这家靠 Claude Code 把 agent 做到最出圈的公司，至今没有一款能和 dots、Muse 正面对标的消费级产品。 没有可爱的形象，没有「你的专属 AI 分身」，也没在任何发布会上宣布过要做。 这家拥有最好的模型、最懂 agent 的公司，为什么偏偏不做个人 agent？ 01 A 社的分布式个人 AI 其实， 在「always-on agent」这件事上，Anthropic 不但没有缺席，甚至比 OpenAI 更早亮出了底牌。 6 月 23 日，比 dots 早了整整三个月，Anthropic 发布了 Claude Tag。 它是一个住在 Slack 频道里的 Claude，团队成员只要 @ 一下，就能把任务交给它。和普通聊天机器人不同，一个频道里只有一个共享的 Claude，有自己的身份和记忆，谁都能看到它在忙什么，A 同事交代的活，B 同事可以接着往下推。 它也会主动干活。Claude Tag 会在没人提问时给出建议，还会去跟进那些已经沉寂下来的讨论串。Anthropic 自己给出了一个很夸张的数字，公司产品团队 65% 的代码，出自内部版本的 Claude Tag。 早在三个月前 Claude 就推出了 Claude Tag｜图片来源：Anthropic 再往前看，桌面端有 Cowork，能接管用户电脑上的文件和应用；开发者那边有 Claude Code，早已能在云端独立跑完一个编程任务，再把 PR 贴回 Slack。 还有一个从没被官方承认的名字，Conway。 今年 3 月 31 日，Anthropic 因为打包失误，意外公开了约 51.2 万行 Claude Code 源码，里面藏着一个独立于聊天界面的 agent 环境。它能被定时任务和外部事件唤醒，有自己的扩展格式，可以控制浏览器、连接各种工具。之后几个月，iOS 版 Claude 的测试版本里还不断冒出 Conway 标签页的新图标。 把这些拼在一起，答案其实很清楚。 Anthropic 并非不做 always-on agent，它只是没有把这件事包装成一个「个人分身」。 OpenAI 和 Meta 卖的是一个有名字、有形象、能帮你订餐厅和买东西的伙伴；Anthropic 卖的是一个坐在工位旁边、能接住工作的同事。前者面向每一个普通人，后者面向一个团队、一家公司。 能力上的差距并没有想象中大， 真正的分野在于，把 agent 放在哪里，以及卖给谁。 02 Personal AI 这门生意 你得承认， 个人 agent 是一门「入口生意」 。 一个 agent 再聪明，用户也得先想起它、打开它，才能把事情交给它。从这个角度看，Meta 做 Muse 几乎是天时地利。它不需要说服任何人下载新 App，WhatsApp 上本来就有数十亿用户，给他们发一条消息，和给 Muse 派一个任务，在交互上没有区别。 OpenAI 的底牌是 ChatGPT。截至当下，ChatGPT 的周活用户在 9 亿量级，dots 直接内嵌其中，从 ChatGPT 和 Codex 都能唤起。对 OpenAI 来说，dots 不是一个新产品，而是给已有的海量用户再加一层黏性。 可惜，Anthropic 手里没有这样的超级入口。 Meta 的
