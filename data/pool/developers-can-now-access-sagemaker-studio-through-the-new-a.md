# Amazon SageMaker Studio

Today, we’re excited to announce that new Amazon SageMaker AI customers can now land inside a fully configured Amazon SageMaker Studio environment in only a few steps after signing up for AWS. You can use a sign-in method that you already have, such as Amazon, Apple, GitHub, Google, or an email address. You don’t need to set up an advanced AWS account, enter a credit card (for most customers), or configure an environment manually. New customers also receive $100 in AWS Free Tier credits that work across SageMaker AI, including model customization, training jobs, Studio notebooks, and endpoint deployments. This post follows on from our previous post, From Hugging Face to Amazon SageMaker Studio in One Click , which introduced deep links from Hugging Face model pages directly into SageMaker Studio workflows. Earlier this year, we also sped up Studio environment creation time from 2 minutes to about 20 seconds and pre-configured model customization permissions in every new Studio domain. Together, these changes removed much of the friction after a developer reached Studio. One major hurdle remained before they got there: creating an AWS account.
