# Sora2 Api

最近做了一个面向开发者的 Sora 2 API ，适合把文本转视频、图片转视频能力接入自己的产品和工作流。

主要能力：
- 支持 Sora 2 和 Sora 2 Pro
- 文本生成视频、参考图生成视频
- 可控制画幅比例和电影感方向，支持多镜头序列
- 生成同步对白、音效和环境声
- 提供 REST API 、任务状态查询和视频结果获取

适合 SaaS 、内容平台、营销工具、内部创意系统和批量视频生产。平台提供 Freemium 体验，付费计划从 $9.90 起。

产品地址： https://sora2-api.com/

这是独立的第三方平台，与 OpenAI 或其他模型提供商没有隶属关系。欢迎做 AI 视频、内容生产或 API 集成的朋友交流。
