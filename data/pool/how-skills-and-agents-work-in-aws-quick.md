# How skills and agents work in AWS Quick

If you use AI agents, you’ve probably explained the same task more than once. You might describe how to build your weekly status update, write release notes, manage a project, or create tickets. These are all repeatable tasks that you can encode using AWS Quick through agents and skills. AWS Quick is an AI-powered service for automating tasks, analyzing data, building web applications, and conducting research. You work with it in natural language, and Quick uses AI agents to process your requests against your connected data sources and applications. In this post, we cover how agents, skills, and your data fit together in AWS Quick, and how to build and share skills that work for your team. We also show how the official catalog and custom agents help you put those skills to use.
