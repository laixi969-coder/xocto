# AI 应用雷达 · 2026-10-11

## 今天的判断

正向方向是明确的：通用助手的入口正在被平台收走，但具体工序的入口正在被打开。Meta Muse 这类把个人 agent 直接放进手机与平板的做法，意味着「帮我代办」这件事会变成系统默认能力；对独立团队来说，正面竞争通用代办已经不划算，值得做的是那些平台不会亲自下场、又必须贴着某一种工作流才能做对的环节——剪辑、架构图、代理分诊、宣传片。

## 市场背景

今天被编辑确认的正式市场背景有两条。一是报道称 2026 年微信进入 AI 元年，公众号全面开放 AI 能力、小程序成为企业新入口；若该开放落地，企业可以在微信生态内更低门槛地部署 AI 应用并触达用户，公众号与小程序的分发与交付方式可能随之改变。二是 Anthropic 更新使用政策，明确禁止用户对 Claude 模型进行辱骂或「虐待」式交互；这属于平台规则层面，对应用开发者的直接影响是交互内容的合规边界被重新划定，具体条款文本与执行方式仍待核验。同日另有多条围绕该政策更新的评论性报道，核心事实相同，不构成独立机会。

## 重点项目

### Meta Muse

普通用户在手机或 iPad 上打开 Meta Muse，把待办、查询或需要代办的请求交给这个个人 AI agent，由它执行动作并返回结果。公开材料没有说明它能处理哪些材料、交付到哪一步、哪些环节仍需人工确认。判断：它的意义不在功能清单，而在于入口位置——当平台把个人 agent 放在设备默认位置，通用代办会变成基础设施而不是产品。需要补的信息是它实际能执行的动作范围与权限边界。

### AdsNotch

Mac 用户在日常用机时打开 AdsNotch，把屏幕（含刘海区域）交给它作为广告展示位，用户按展示获得收益。广告主一侧的投放方式、计价与结算规则，以及 AI 在其中具体承担什么动作，公开材料均未说明。判断：把个人设备界面当作可售卖库存，方向成立但风险集中在广告主侧是否真的愿意买这种库存，以及平台规则是否允许。

### adu-motion-video

做口播或知识讲解的创作者录完音频、攒好素材后，在 adu-motion-video 里挑一个动效模板和风格，再让 Codex 或 Claude Code 按模板把口播与素材剪成成片，交付是可直接发布的视频。判断：剪辑入口正从时间线软件转向「模板 + 编码助手」，原本靠手工关键帧的动效工序被模板化，这是平台不会亲自做的细活。

### AgentDock

开发者同时跑 Claude Code 和 Codex 时，在 AgentDock 的统一收件箱里接收并回复各代理抛出的提问，不必在多个终端窗口之间来回切换，交付是完成一次代理确认或回复。判断：编码代理从单会话走向并行多开，人的角色变成分诊和确认，这个位置会越来越挤，但先做收件箱的人有习惯优势。

### ai-promo-video-maker

独立开发者、SaaS 或课程团队要发产品宣传片时，把产品名或网址交给 Cursor、Claude Code 这类编程代理，它自己去调研产品、出多套风格样图让人挑、截 4K 真实页面、按音乐节拍卡点剪辑。判断：宣传片原本按条外包、按剪辑工时计价，现在被拆成调研、截图、卡点、配音、审图几个可自动执行的步骤，计价方式会跟着变。

### NIMO

面向日常佩戴场景的 AI 眼镜品牌，用户在通勤、会议或出行时通过眼镜完成语音交互、拍摄与信息查看。候选材料仅披露融资与估值，具体硬件形态、AI 功能边界与交付方式仍待核验。判断：AI 眼镜正从概念走向有资本下注的消费硬件品类，可穿戴入口的竞争在升温，但硬件交付与售后是独立团队最难的一环。

### anyCreature by Gobkit

从现有材料看，它面向使用 AI 代理的人，在代理运行过程中召唤出怪物形象；具体接收什么输入、生成的是图像还是可交互角色、最终交付什么，公开材料未提供细节。判断：代理产品开始往娱乐和陪伴方向延伸，把「调用工具」变成有角色和情绪反馈的互动，但形态不清时不宜下结论。

### architecture-canvas

系统架构师在写方案或做评审前，把需求文档、系统说明等材料交给它，由模型读取并生成可继续编辑的架构图，输出落在本地工作区的 Excalidraw 画布上，人仍需自己核对和调整图形。判断：文档到图表的转换正从手工拖拽转向模型出初稿，本地工作区这一点对不愿把内部文档上传外部服务的团队是关键卖点。

## 其他信号

Vercel 的 CLI 现在允许代理直接购买域名，部署存储开始对既有 Pro 团队计费，新 Pro 团队默认 30 天部署保留；AWS 侧有 Bedrock、AgentCore 与 Strands 的九月更新汇总，以及 Postman 在 Bedrock 上为 4000 万开发者运行 Agent Mode 的工程复盘。这些属于基础设施与计费口径的变化，会改变小团队的交付成本结构，但今天不构成独立产品机会。
