## 一句话定位

一个约 15MB 的 Rust 单二进制编码 agent，把 llama.cpp 推理引擎、grep、git 全塞进一个文件里，
断网也能用本地 GGUF 模型跑完整条"读代码—改代码—跑测试"的回路，也能接任意云端模型。

## 做这个东西的人

Antigma Labs（antigma.ai）出品，核心作者自述专注"harness 而不是模型"。
公开仓库 Apache-2.0，仓库 2025-12-23 创建，目前 1,680 star / 52 fork，最新版本 v0.preview.78。
核心 harness 以预编译二进制分发，源码在私有仓库开发，开源部分是文档、协议（protocol-shape）、
SDK（agent-sdk）和评测流水线（ante-harbor）。

_判断：把"打包"当成产品核心、用公开评测（Terminal-Bench）当信任状，这两件事是同一个赌注——
在 agent 工具同质化的阶段，靠工程和透明度抢开发者。_

## 它到底能做哪几件事

- **单二进制跑四种形态** → 交互 TUI（`ante`）、无头一次性任务（`ante -p`，适合 CI）、
  长驻 server（`ante serve`，JSONL 协议，接编辑器插件）、gateway（`ante gateway`，当 Slack/Discord bot）
- **内置本地推理** → 固定版本的 llama.cpp，指向任意 GGUF 文件即可离线跑，
  无需 API key、账户和联网；也支持 12+ 云端提供商（Anthropic、OpenAI、Gemini、DeepSeek 等）且可切换
- **嵌入常用工具** → grep 和 git 直接编进二进制，不 shell 出去调外部程序
- **多 agent 与记忆** → 子 agent 编排、MCP、跨会话持久记忆
- **命名配置档（profiles）** → 同一二进制用 `--profile` 切换不同系统提示词/工具集/技能组合，
  内置极简的 `bare` 档，社区可分享新档
- **可验证的评测** → 在 Terminal-Bench 2.1 上按官方排行榜约束持续公开评测，
  每次结果绑定一个可下载的构建版本，可审计

**它明确不做**：不做账户强制（README 写"不需要账户，甚至不需要我们的账户"）、
不锁定单一模型供应商。遥测默认开但可 `ANTE_TELEMETRY=off` 关，只发匿名安装标签。

## 它在替代什么旧行为

用编码 agent 干活，过去默认要装一套运行时和依赖：Node 环境、Python 环境、编辑器插件、
一堆包树，还要配好 API key 或者本地起一个 Ollama 之类的推理守护进程。
"环境漂移"是常态——上周能跑的容器这周就静默失败。

Ante 替代的是这一整套安装与运行假设：一个文件，`curl | bash` 完事，
要本地跑就把 GGUF 文件指给它，不用起任何守护进程。

离线这半边替代的是另一个旧行为：军工、医疗、金融这些隔网环境，过去基本与 agent 无缘——
"你的代码永不离开机器"对这类用户不是卖点而是入场券。以前他们只能手动改代码，
现在多了一个能断网跑 agent 的选项。

## 商业模式

**alpha 免费**。预编译二进制在 alpha 预览期免费（含商用），按 BINARY-TERMS.md 授权；
开源部分 Apache-2.0。README 提到一个可选的托管服务 antix.antigma.ai，暗示未来商业化方向，
但无定价。

_判断：这是 open-core 的老路——二进制免费圈人，未来靠托管层收钱。但当前连"是否需要云"
都没说死，商业模式本身还没立起来。_

## 判断

**这是"BusyBox/SQLite 哲学应用到 agent"的产物：打包方式本身就是产品主张。**
别的 agent 拼模型和提示词，Ante 拼的是"不装环境、不联网、一个文件就跑"。
对想并行跑几十上百个 agent 的团队，harness 的重量从四舍五入变成账单本身，
这个方向成立。

**它和 Cloud Code 们最大的分歧在信任模型。** 核心 harness 闭源、预编译分发，
而它的整个卖点是"代码不出你的机器"——需要离线 agent 的恰恰是监管和涉密行业，
恰恰是最不会凭信任跑一个无法审计二进制的人群。开源部分（SDK、协议、评测流水线）
开放了，但"你真正运行的那个东西"不能完整检查。作者承诺逐步开源核心 crates，
在做到之前，pitch 和 license 在互相打架。

**评测数字要打折扣看。** 82.7% 用了云端 DeepSeek 模型，和"离线"是两套配置；
自报的离线数字约 56%，比前端配置低约 25 个百分点。买离线功能的人付出的是真实代价，
这笔账必须摆在桌面上。

**可迁移的规律：单文件分发是把安装成本砍到零的最彻底做法。**
不用安装器、不用依赖树、不用守护进程，一个 curl 管道就完事——
对开发者工具的转化率，安装成本的影响被系统性低估。

## 下一步看什么

① 核心 harness 的源码是否兑现"progressive"开源承诺——开源进度即信任修复速度
② 是否提交 Terminal-Bench 官方排行榜——自报 82.7% 上了官方榜才是真数字
③ 托管服务 antix 的定价与形态——这是从免费圈人到商业模式的第一步

## 可借鉴的做法

**产品逻辑**：如果你的工具面向"并行跑很多 agent"或"隔网环境"两个场景之一，
"单二进制 + 零运行时依赖 + 可选本地推理"是值得复制的架构决策；但要先想清楚
闭源 vs 开源的信任成本——承诺离线隐私的产品，不能给用户一个无法审计的二进制。

**话术**："No account required, not even with us"——把"无锁定"表达成对用户最低的
承诺门槛，比罗列支持多少供应商更有记忆点。

**定价结构**：alpha 免费商用 + 未来托管层的 open-core 路径是当前 agent 工具的默认结构，
可以观察但不必复制；真正的问题是托管层和免费二进制之间是否有人愿意付费。

## 结论

**值得关注。** 打包哲学和评测透明度在同类里罕见，HN 讨论热度真实（159 分、88 评论）。
但信任模型（闭源核心）和离线性能（-25 分）是两个需要兑现的承诺。
三个月后拿上面三条验证，尤其第一条——它决定这个项目是"真开源"还是"开放外壳"。
