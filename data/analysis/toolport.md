## 一句话定位

一次配置所有 MCP server，所有 AI 客户端共用一个本地网关；
按需加载工具定义省 token，密钥锁进系统钥匙串。

## 做这个东西的人

独立开发者 "Tyler"（GitHub tsouth89、发布平台 @tsouth2），单人项目。
2026-06-23 以 "Conduit" 的名字首次上 发布平台，2026-08 第三次发布，
日榜 #5、149 票，版本已到 v1.12.0。无融资，靠 GitHub Sponsors，
官网 toolport.app。

_判断：这是"配置复杂是采用率隐形杀手"这个判断的最直接产品化。
一个人两个月从 0 做到 v1.12、有可复现 benchmark、有跨平台安装包，
技术执行力在同体量工具里排前列。_

## 它到底能做哪几件事

- **本地 MCP 网关**：每个 server 配一次，Claude Desktop、Cursor、VS Code、
  Windsurf、Codex 等 29+ 客户端共享
- **懒加载工具发现**：不把所有工具 schema 塞进上下文（挂 3 个 server 每次
  请求就约 2.4 万 token 固定开销），只暴露 4 个搜索式 meta-tools，按需拉取；
  自称同等任务成功率下省 74-91% token，有公开可复现 benchmark
- **密钥管理**：API key 存 OS keychain，运行时注入，不进配置文件
- **完整性检查**：给每个工具定义做 hash 指纹，server 改了定义就报警
  （防 rug pull / tool poisoning）
- **治理**：每 agent 作用域开关、破坏性调用需人工批准、审计日志、延迟监控
- **跨平台**：Tauri/React 桌面应用 + Rust 网关，另有 headless Docker 网关

## 它在替代什么旧行为

两个。**一是"扁平工具加载"**：以前每个 MCP server 每次请求都把全部工具定义
发给模型，工具越多固定 token 开销越大。它用 meta-tool 按需发现替代
"一次全量加载"。

**二是"每个客户端各配一遍"**：以前同一套 MCP 配置 + 明文 API key 要往
每个客户端里粘贴一遍，改一个 server 要同步 N 个文件，还会漏。
它替代"多客户端配置漂移"——一次配置、处处可用。

## 商业模式

开源核心（MIT，本地应用免费）+ Toolport for Teams 订阅：
免费最多 5 人；$39/月（5 人）+ $12/人/月，托管或自托管同价，年付约 $390/年。
付费客户数：未披露（第三方调研称未见任何披露）。

_判断：个人免费建口碑、团队订阅卖治理，是个体户能做的最小商业闭环。
但 $39/月的团队档要跟微软、Docker、IBM、Kong 的免费 MCP 网关抢人，
这个定价的生命力存疑。_

## 判断

**技术执行是这批小工具里最扎实的之一，商业模式是它最弱的一环。** 值得记三个点：

**一，把可量化的浪费做成卖点。** "每次请求固定浪费 2.4 万 token"是一个
开发者立刻能理解的数字，还配了公开可复现的 benchmark——基础设施工具的
说服力来自测量，不来自口号。这个做法任何做效率工具的人都该抄。

**二，安全设计是 MCP 网关的参考实现。** 工具定义 hash 指纹（server 改了
定义就报警，防投毒）、破坏性调用人工批准、密钥只进 keychain——这组机制
适合任何"agent 调用外部工具"的产品，值得整套拿走。

**三，结构风险是它的命门。** 懒加载这个核心能力正在被客户端原生吸收——
Claude Code 已经开始延迟加载 MCP schema，一旦所有客户端原生支持按需加载，
meta-tool 的差异化归零。同时微软、Docker、IBM、Kong 都在免费开源
MCP 网关，个体户要在平台玩家的免费产品旁边收 $39/月，通道很窄。
它的价值更接近"先行者的最佳实践"：把 MCP 网关该有的功能一次性做齐，
读者把它当参考实现抄，而不是当投资标的。

## 下一步看什么

① 付费 Teams 客户是否出现（现在零披露）——这是它唯一的收入路径
② 三个主要客户端（Claude Code / Codex / Cursor）原生 MCP 延迟加载是否彻底落地
   ——落地即终结
③ GitHub stars 与 fork 三个月后的走势——衡量它作为参考实现被采用的程度

## 可借鉴的做法

**产品逻辑**：找到用户每次请求都在浪费的固定成本（token、配置、时间），
把它量化成"省 74-91%"这种可测量承诺，并公开测量方法——
效率工具的说服力来自可复现的数据。

**安全设计**：工具定义 hash 指纹 + 破坏性调用人工审批 + 密钥只进 keychain，
这套"agent 调用外部工具"的防线可以直接搬到自己的产品里。

**定价结构**：个人免费开源建口碑，团队订阅卖治理（共享配置、每人本地密钥）
——个体户能做的最小商业闭环，虽然前景存疑。

## 结论

**值得关注，但很难下注。** 技术值得抄，商业模式值得怀疑——
当平台把免费方案做进客户端，独立网关的窗口可能只有一到两个版本周期。
三个月后看付费客户与客户端原生化进度。
