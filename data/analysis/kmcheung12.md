## 一句话定位

一个用照片三维重建（photogrammetry）把自己常去的攀岩馆搬进网页的个人项目：iPhone 14 拍十分钟，生成可拖拽的 3D 岩馆，每面墙标好线路、把攀爬视频贴回它实际发生的位置，还能第一人称在馆里走。它主张"攀岩记录的正确方式不是照片也不是视频，而是 3D"。

## 做这个东西的人

GitHub 用户 kmcheung12，个人项目，网页托管在 GitHub Pages。仓库创建于 2026-07-23，作者全名与背景未在页面上披露。

_判断：这是"我的楼下"式个人项目——不做成通用产品，只为解决自己"记录攀爬"的痛，反而因为具体而真实。_

## 它到底能做哪几件事

- **3D 岩馆漫游** → 拖拽看全馆，包含悬岩岛、slab 岛等区域，可第一人称 WASD 行走
- **线路标注** → 每条线路（problem）的起点/终点色点、握点数（如"Route 2 有 19 个 hold"）标在墙面上
- **把攀爬视频贴回墙面** → 原本躺在 WhatsApp / Instagram 里的尝试录像，被放回它实际发生的位置
- **可绕行的攀爬者** → 视频中的攀爬者变成墙上可绕行观察的 3D 身体，能看出正面镜头看不到的转髋动作

## 它在替代什么旧行为

两件旧事。

一是**岩馆与线路的记录与分享方式**：以前是照片（压平了墙）和视频（固定机位），要么感觉不到地形、要么只能从手机所在的角度看。替代成可绕行的 3D 空间。

二是**攀岩者的预习方式**：岩友习惯站在墙前读线（先想好手往哪放），或翻教练/岩馆的社交媒体找线路预览。这个项目把"读线"从到店前搬到网页上——你可以在去岩馆之前就在 3D 里把序列想好。

_判断：对攀岩来说，路线是 3D 空间里的信息，照片和视频都损失了一个维度。这个项目补回的正是那一维。_

## 商业模式

## 判断

**个人项目最有力的传播资产是"具体"。"我家楼下的岩馆"比"摄影测量技术"有效一万倍**——HN 的 28 分买的就是这份具体。这个项目没有任何产品企图，却完成了最好的产品演示：让读者当场看到"物理空间的 3D 化"能带来什么新信息。

**可迁移的规律：给空间内容加"叙事层"。** 纯粹的 3D 扫描是数据，加上线路标注、第一人称讲解、视频回贴，数据就变成可消费的内容。任何做空间/场馆/实体产品数字化的团队，都能抄这套"扫描 + 标注 + 导览"的组合。

**局限**：它依赖的是 iPhone 自带的摄影测量 + 网页渲染，技术上没有新东西；价值全在"格式"和"具体"。要成为产品，还需要解决大规模采集、更新、版权等问题，目前一个都没碰。

## 可借鉴的做法

**内容逻辑**：做展示型项目，选一个"读者身边的、具体的"对象，而不是抽象的"演示数据"。具体对象的传播力来自读者能对照自己的生活想象它。

**格式模板**："3D 扫描 + 信息标注 + 第一人称导览 + 多媒体回贴"这套组合可以直接复用——对任何实体空间（门店、展厅、工作室、健身房），这套格式都是现成的内容/产品模板。

**话术**：无。这是作品不是产品，没有商业话术可抄。

## 结论

**值得关注，但作为"格式"而非"产品"。** 技术无新意、产品无意愿，但它把"空间 3D 化的正确内容形态"演示得很清楚。对做 AI+创作或空间数字化的人，这是一份免费的格式范本。
