## 一句话定位

MiniMax 的通用 AI Agent，定位是「你的 AI 智能伙伴」：说一句话，它去做网页、做小游戏、做产品原型、做 PPT，不再是一句一句地回话。

## 做这个东西的人

上海稀宇科技（MiniMax），2022 年初成立，创始人兼 CEO 闫俊杰（前商汤科技副总裁）。公司 2026 年 1 月 9 日在港交所上市（00100.HK）。这是国内少数从 C 端产品矩阵（海螺 AI、MiniMax Audio、星野/Talkie）反向验证模型、再打进 B 端的公司。

**注意区分入口**：这是 流量榜 收录的「MiniMax - 通用AI Agent」应用入口（你的 AI 智能伙伴），与公司旗下的海螺 AI、星野是并列的产品线，不是同一个东西。三大业务板块分别为：通用 Agent、多模态平台（海螺）、AI 情感陪伴（星野）。

_判断：闫俊杰是做视觉和算法出身的老兵，MiniMax 的打法一直是"全模态自研 + C 端产品自己压测"。通用 Agent 是他们三个人均付费最高的产品线，也是讲上市故事最顺的那块。_

## 它到底能做哪几件事

- **长程任务执行** → 制作网页、小游戏、产品原型、PPT，先制定工作计划、与用户确认再动手，模块可继续在对话里改
- **多模态调用** → 底层 M 系列模型（M2/M2.1/M2.5/M2.7），一个 Agent 可调用文本、语音、图像、视频生成
- **本地化执行** → 基于 OpenClaw 衍生出 MaxClaw，把通用 agent 接到本地电脑上跑任务
- **开放平台** → 面向企业和开发者的 API 接入，开发者可在自己产品里挂上 agent 能力

它和聊天助手的区别是：聊天助手一句话来一句话回，它是接受一个目标、拆解步骤、调动工具、交回一个成品。

## 它在替代什么旧行为

替代的是**"为每个产出物分别找工具或找人的动作"**。

以前想做一个网站原型，要开设计工具、写代码、或者找外包和同事；做一个 PPT 要打开 Office 手动排。MiniMax Agent 把这些"换个工具、换个执行者"的动作压成一句话，让一个人对着一台电脑说出需求就能拿到成品。它对标的是"一人干完一个产品的完整流程"——公司高管在访谈里的原话是"一人开公司"。

_判断：这个替代成立的先决条件是"说清需求"比"用工具"更便宜。对会用设计工具和写代码的人来说它只是省事，对不会的人来说它打开了一扇以前进不去的门。MiniMax 的赌注押在后者。_

## 商业模式

订阅 + API 两条腿。C 端 Agent 订阅制（平均付费 73 美元/人），开放平台 API 按量计费（B 端累计 13.2 万用户，平均支出 6167 美元——企业客户远高于个人）。公司整体 2026 年 2 月 ARR 破 1.5 亿美元，2025 全年收入 7903.8 万美元、同比增长 158.9%，其中约 73% 来自国际市场。

## 硬数字

- 流量榜 口径：**3.79M 月活，环比 -1.33%**，同时挂国内增速榜、国内总榜、全球总榜
- MiniMax Agent 人均付费 73 美元，为全产品线最高（海螺 AI 为 56 美元）
- 开放平台 B 端用户 13.2 万，人均年支出 6167 美元
- 公司累计服务 2.12 亿+ 个人用户、10 万+ 企业客户与开发者，覆盖 200+ 国家
- 2026 年 1 月 9 日港交所上市，2026 年 2 月 ARR 破 1.5 亿美元

## 四维评估

| 维度 | 结论 |
|------|------|
| 创始人-产品匹配度 | 创始人算法老兵出身，公司从模型到 C 端产品自建，匹配度高 |
| 产品洞察力 | 抓住"聊天助手不产出成品"的缺口，把长程任务执行做成独立产品线 |
| 技术实现质量 | M 系列多模态模型 + 本地化 agent（MaxClaw），产品矩阵证明工程可落地 |
| 市场时机 | 通用 Agent 是 2025-2026 各家必争的定义权之战，MiniMax 有付费数据背书但用户盘子小于头部聊天产品 |

## 判断

**值得关注。** 它是"通用 Agent"这个赛道里少数有硬收入数字的玩家：上市、ARR 破 1.5 亿美元、Agent 人均付费 73 美元、B 端人均支出 6167 美元。这些数字说明它在做真生意，不是概念。

但要把两件事分开。其一，**3.79M 月活环比 -1.33%**，说明这个产品线没有在起量，更像稳定的小盘子——通用 Agent 的付费质量高（人均 73 美元），但人群小。其二，**"通用 Agent"是定义权之争**，豆包、Kimi、千问、腾讯元宝都在用同一个词，MiniMax 的差异化是"多模态全自研 + 从陪伴产品积累的全球分发"，但这在 C 端聊天市场并不构成壁垒。

_判断：它的商业故事最好的一面是"企业客户人均支出 6167 美元"——说明真正的大钱在 B 端，不在 C 端订阅。C 端的 Agent 更像品牌广告，B 端的 agent 能力才是收入来源。看它要看 B 端，别看月活。_

## 下一步看什么

① 3.79M 月活的环比能否转正——Agent 产品线是否进入起量阶段
② B 端（开放平台 13.2 万用户、人均 6167 美元）的增速有没有在财报里继续放大
③ MaxClaw 本地执行方向的采用情况——它是把 agent 从"聊天框里做 PPT"推向"真在电脑上干活"的桥

## 可借鉴的做法

**产品逻辑**：给"聊天助手不产出成品"的缺口造一个独立产品线，并明确告诉用户它与聊天助手的区别（接受目标、拆解、调工具、交成品），而不是混在同名产品里。定义不清是通用 Agent 赛道的普遍病，谁先把区别讲清楚谁占便宜。

**定价结构**：同一个产品线区分 C 端订阅（人均 73 美元）与 B 端 API（人均 6167 美元）——两条腿走，让企业客户按量付费覆盖成本，C 端做普及。这种"C 端做量、B 端做钱"的结构可以直接参考。

**话术**：无。官网没有值得偷的独特句式。

## 结论

**值得关注。** 有真收入、有真数据、已上市，通用 Agent 的盘子虽小但质量高。跟踪重点是 B 端增速与本地执行，而不是那个不动的月活数字。
