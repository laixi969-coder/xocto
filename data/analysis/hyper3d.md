## 一句话定位

用文字或一张图在几秒内生成可用的 3D 模型：产出的是带正确拓扑、
UV 和 PBR 材质的「生产就绪」资产，而不是需要美术清理的粗糙模型，
面向游戏、影视、电商和具身智能的训练场景。

## 做这个东西的人

Deemos Tech（影眸科技），中国上海公司，95 后团队，CTO 张启煊（Qixuan Zhang）。
产品 Hyper3D Rodin 2024 年 6 月发布后迅速突破百万用户，背后的生成技术
论文 CLAY 提名了 SIGGRAPH 最佳论文，是 NVIDIA Inception 加速计划成员，
并与 NVIDIA 合作在 Omniverse / OpenUSD 上做了 Sim-Ready 仿真兼容。

_判断：这是「学术成果产品化」做得最好的国内 3D 生成团队之一——
SIGGRAPH 最佳论文提名是技术地位的国际背书，而他们用了 16 个月、
平均每 9 天上线一个新功能的速度把它变成了产品。3D 生成赛道
（Tripo、Meshy、Luma 等）都在做同一件事，影眸的差异点
是「生产就绪」这个标准：别人出模型，它出能直接进引擎的资产。_

## 它到底能做哪几件事

- **Image to 3D / Text to 3D** → 图片、草图、多视图或文字提示生成 3D 资产，
  自带几何、UV 和 PBR 材质
- **3D 编辑** → 局部编辑（只改选中区域）、迭代拆分（拆成可编辑部件）、
  支持 .obj/.fbx/.glb 导入修改
- **精细控制** → 3D ControlNet：边界框、体素、点云引导生成；
  Smart Low-Poly 把高细节资产优化成低多边形
- **生成速度** → Gen-2.5 四档模式：Extreme-Low 约 4 秒、Low 约 9 秒、
  Medium 约 20 秒、High 约 40 秒、Extreme-High 约 80 秒；支持千万级多边形
- **生态工具** → AI 头像生成、AI 纹理生成、OmniCraft HDRI 环境贴图
- **交付格式** → GLB、FBX、OBJ、STL、USDZ；插件覆盖 Blender、Unity、
  Unreal、Godot、Cinema 4D、Maya、Omniverse、3ds Max
- **API 与企业版** → REST 推理 API；SSO/SAML、团队管理、共享资产工作区

**它明确不做**：不做本地建模软件——所有生成在云端完成，
它卖的是「生成能力」和「资产」，不是取代建模师在 Blender 里的全部操作。
局部编辑和拆分功能也在云端做，不落到本地工作流。

## 它在替代什么旧行为

**替代的是「专业软件手工建模」这个最贵的环节。**
以前一个能进游戏引擎的 3D 资产——带正确拓扑、UV 展开、PBR 贴图——
是 3D 美术用 Blender/Maya 花数小时到数天做出来的，还要求操作者
掌握拓扑和展 UV 的专业知识。AI 生成把这个流程压缩到分钟级，
把「会不会用专业软件」这个门槛抹掉了。

**替代的是「2D 概念艺术到可用模型之间的手工翻译」。**
游戏和影视里最常见的老流程是：概念图一张 → 建模师照着搭 →
拓扑修 → 展 UV → 贴图 → 检查能不能动。中间全是手工。
Rodin 的做法是让模型直接理解「物体由哪些部件组成」，
一张概念图直接产出带结构理解的资产，手工清理的环节被拿掉了。

**对具身智能团队，替代的是「给机器人训练造仿真资产」这件事。**
以前训练一个机械臂，需要人工建模并手动给每个资产配物理属性；
Sim-Ready 功能让生成的资产直接带物理属性、以 OpenUSD 导出，
进 Isaac Sim 就能训练——官方称该功能上线后试用转化率达三分之一。

## 商业模式

**Freemium + API 按量 + 企业版。**
- 免费档：注册即可生成，社区画廊展示作品
- API：按量计费，面向游戏、电商批量生产场景
- 企业版：SSO、团队管理、资产共享，面向工作室和公司
- 网页未公开具体价格，付费需进工作区

_判断：它的商业模式和 Meshy/Tripo 类似——免费试用建立口碑，
API 和企业版赚钱，UGC 游戏合作（千万人实时在线的游戏里
用户生成萌宠）是隐藏的收入渠道：游戏用户每生成一个资产
都可能是一次 API 调用。这个「被别人的产品吃掉」的嵌入式
收入模式，比独立卖会员的天花板高得多。_

- 技术论文 CLAY 提名 SIGGRAPH 最佳论文；SIGGRAPH 2024/2025 均获认可

## 判断

**值得关注——mom +134% 需要拆开看，但技术地位是真实的。**

312 万月访问、环比 +134.62%，这个涨幅大概率是几件事叠加：
Gen-2.5 发布带来的「4 秒生成」话题度、千万人级 UGC 游戏的合作导流、
以及 流量榜 榜单带来的流量口径变化。上一轮基数不高（约 133 万），
绝对值仍在 300 万级。真正的验证要等下月环比能否延续，
而不是盯着单月数字。

**它的技术叙事是可信的**：SIGGRAPH 最佳论文提名、NVIDIA 官方博客背书、
百万用户——这三样叠加说明它不是营销驱动。3D 生成赛道的真实差距
不在「能不能生成」，在「生成的能不能直接用」：
拓扑对不对、UV 展开干不干净、能不能进动画和仿真管线。
影眸把「生产就绪」当产品标准，这是它区别于 Meshy/Tripo 的位置。

**要打的问号**：第一，商业化数字（ARR、付费用户、游戏合作的收入分成）
全部未披露；第二，UGC 游戏合作是单一客户依赖还是一条可复制渠道，
需要更多案例；第三，它的免费档会不会重演「生成免费、导出收费」的
老套路——这决定独立创作者的口碑能不能持续。

## 下一步看什么

① 下月环比能否延续 +134%——是真起量还是 Gen-2.5 发布的一次性冲高
② 有没有第二个公开的 UGC/平台级合作案例——验证嵌入式渠道是不是可复制的
③ API 付费用户数和企业客户（游戏工作室、电商）是否公开披露——商业化的成色

## 可借鉴的做法

**产品逻辑**：做「生成类」工具时，把「生产就绪」当成产品标准而不是
宣传词——用户不关心你生成了多好看的预览，关心的是
「生成的能不能直接进我的管线」。局部编辑、拆分、可编辑拓扑
这些「生成之后还能改」的能力，是工具从 demo 变成生产力工具的分水岭。

**商业模式（嵌入式）**：把能力嵌入别人的产品（UGC 游戏、电商平台），
用户每生成一次就是一次 API 调用——这种被吞进别人产品里的收入模式，
比独立卖订阅的天花板高。前提是你的能力足够便宜和快，
快到别人的产品愿意把生成按钮放在自己界面里。

**话术**：无。官网文案是行业标准的产品页，没有可偷的句式。

## 结论

**值得关注，但商业验证未完。** 技术地位真实（SIGGRAPH、NVIDIA、百万用户），
「生产就绪」的差异化成立，mom +134% 更像产品发布冲高而非稳态。
记下来，下月验证环比，再等它披露商业化数字。
