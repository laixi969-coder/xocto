## 一句话定位

非官方复刻 Kimi 的 PPT 生成能力，攒到 1600 星，然后因版权被清空。

## 现在的状态：仓库已空

README 现在只剩两句话：

> 因版权原因，本仓库内容已全部清空。
> This repository has been cleared due to copyright reasons.

代码没了，星还在。**这份分析的价值不在产品本身，在它是怎么死的。**

## 它原本能做哪几件事

从清空前的描述还原：

- **给 AI Agent 用的 Slides 技能** → 让 Claude Code、Codex 这类编码 agent 能生成演示文稿
- **输出可编辑的 PPTX** → 不是导出图片或 PDF，是能在 PowerPoint 里继续改的文件
- **附带本地浏览器编辑器** → 生成完可以直接在本地预览和微调

**它明确不做什么**：不做设计模板库，不做在线协作。
它只解决"让 agent 能产出可编辑的 PPT"这一件事。

## 它在替代什么旧行为

用 AI 做 PPT 的实际流程：让模型写大纲 → 自己复制到 PowerPoint → 手动排版 →
发现结构不对再回头改。中间的复制粘贴和排版是纯体力活。

它要替代的是这段体力活。**旧行为明确，痛点真实** ——
「可编辑」三个字是关键，AI 生成的东西如果不能改，在真实工作里就用不了。

## 商业模式

开源免费，无变现设计。这也是它的死因之一：**没有商业实体，就没有法务能力应对投诉。**

## 硬数字

- 开源关注 1603
- 存活时间：不详，但从星数看至少积累了几个月
- 当前状态：**代码已清空**

## 判断

这个项目最值得记的地方是：**它验证了需求，然后被自己的定位杀死。**

1600 颗星说明"让 agent 产出可编辑 PPT"是真需求 —— 这个数字比任何用户访谈都硬。
但它在名字里放了「Kimi」，在定位里写了「非官方」，等于主动把自己放在了
被投诉的位置上。同样的功能，换个名字、不声称复刻任何人，大概率还活着。

**可迁移的规律：在别人的品牌上做产品，你的天花板不是能力，是对方的容忍度。**
这个容忍度可以在任何一天归零，而且不需要理由。

代价是完全的：不是罚款，不是改名，是代码全部清空。
1600 个 star 变成一块墓碑 —— 它们还在，指向的东西没了。

这件事对整个「AI Agent Skill」生态是个信号。现在大量 skill 是围绕某个具体产品做的
（复刻它的能力、扩展它的功能、绕开它的限制）。**这类 skill 的法律地位从来没被测试过，
现在测试结果出来了一个。**

## 下一步看什么

1. **有没有人改名重开** —— 如果同样的功能换个中性名字重新出现并活下来，
   就证明问题出在命名而不是功能
2. **Kimi 官方会不会自己做** —— 投诉之后往往跟着官方版本，那说明它验证了对方的需求
3. **其他复刻类 skill 会不会跟着消失** —— 这是判断这次是个案还是转折的关键

## 可借鉴的做法

**这一条对任何围绕现成产品做能力的人都有实操价值。** 教训很具体 ——

- **不要在产品名里带别人的品牌。** 哪怕加了「非官方」也没用，那反而是自认
- **不要在描述里声称复刻或兼容某个具体产品。** 描述你解决什么问题，不描述你像谁
- **1600 星保护不了你。** 用户量不是护城河，法务能力才是

**反过来看的机会**：这个需求被验证了，位置现在空着。
一个不碰任何品牌、只讲「让 agent 产出可编辑演示文稿」的项目，现在进场正是时候。

## 结论

**证据不足。** 产品已经不存在，但它留下的教训比大多数活着的产品更有用。
留在库里作为一个案例，不作为一个产品。
