## 一句话定位

不是把 DSH 的聊天框变大，而是把整个开发环境塞进它的侧边栏：文件树、编辑器、终端、Git、后台任务、内嵌浏览器，一个插件装齐，让 agent 干活时人不用再切窗口。

## 做这个东西的人

omdsh-dev 组织的核心作者 Menghuan1918（GitHub 同名账号）。仓库建于 2026-08-07，在 DSH 官方 8/13 公开之前——内测期就动手的社区作者。MIT 协议，TypeScript，npm 包 `dsh-better-sidebar`，当前 v0.10.3，112 个提交。

_判断：敢在官方正式发布前一周就押注一个具体界面插件的方向，说明作者要么有内测渠道，要么在赌官方会留这个坑。从结果看赌对了——官方正式发布时右侧栏确实是空的（有实测者明确写"右侧栏还没做出来，缺少 Codex 那样的内置浏览器、文件管理、预览等能力"），而这个插件把坑填上了。_

## 它到底能做哪几件事

- **文件浏览与编辑** → 懒加载目录树（根 = 会话 cwd）、CodeMirror 6 多语言编辑、Ctrl/Cmd+S 原子保存、图片/Markdown/HTML/PDF/Word/Excel/PPT 内联预览
- **真实终端** → xterm.js + node-pty，每会话 3 个 UI 上限，可注入 8 个 `terminal_*` 工具给 agent 用
- **Git 面板** → 真 diff + VSCode 式 diff tab、右键暂存/放弃/提交/还原
- **后台任务页** → 主会话 agent 拓扑、实时工具调用轮询、强制终止
- **底部面板 + 分栏** → 独立第二工作台、Tab 拖拽拆分合并、移动端 <768px 自动切换
- **三方扩展接口** → 暴露 `ctx.betterSidebar` 服务，别的插件可注册新 Tab 和新文件预览器（内置 7 tab + 9 viewer）
- **按需加载** → 启动只拉 ~325KB 核心，打开 .xlsx 才拉 Univer（~20MB），打开终端才拉 xterm

**它明确不做**：不做 Git push/pull/fetch（只做本地操作），不放开浏览器对 localhost 等本机地址的访问（默认拒绝，可临时解锁）。安全和范围克制得很清楚——这是个工作台，不是又一个 IDE 套壳。

## 它在替代什么旧行为

DSH 官方发布时以 Web UI 为主，但右侧栏是空的。于是 DSH 用户的实际工作流是：浏览器里开着 agent 对话 → 文件改动切到外部 IDE/编辑器去看 → git 操作切到终端手动敲命令 → 跑测试再切回来贴结果。一次任务来回切三个窗口，状态还要人肉记住。

better-sidebar 替代的就是这套"人肉 glue"。它把文件、编辑、终端、git、任务状态全部收进侧边栏，agent 干活的时候，人在同一个界面里盯结果、看 diff、回滚。它替代的不是某个工具，而是"在 agent 和开发环境之间反复横跳"这个行为本身。

## 判断

**这是一个把"IDE 该有的"和"插件该做的"分得很清楚的补位产品。**

它最大的动作不是做功能，而是做边界：文件、编辑、终端、git 属于工作台底盘，自己做；新 Tab、新预览器开放给别人注册。这个分工是它和后面所有侧边栏类插件拉开差距的地方——它不跟官方抢地盘，它给整个生态提供地基。

**可迁移的规律：面向开发者的 AI 产品，第一版界面功能宁可少，也要留扩展点。** 官方把右侧栏留空，社区用一周就把它填满了——对平台方来说，"留一个可见的坑"是最便宜的生态启动方式。

**它的天花板也很清楚**：它是 DSH 的插件，DSH 活着它才有价值。官方如果哪天一版更新把侧边栏补全（参考官方曾移除 TUI、又把 Web UI 定为主路径的历史），它的核心价值会被官方顺手覆盖。当前 520 星说明它有先发，但没有证明有不可替代性。

## 下一步看什么

① 官方 Web UI 会不会在 2-3 个月内把侧边栏补全——补了，它的差异化就只剩扩展接口
② 第三方注册的 Tab/Viewer 数量是否增长——这是它"地基"定位是否成立的证据
③ 版本更新节奏是否跟得上 DSH 官方 rc 迭代——插件跟着上游 rc 走，跟慢一步就装不上

## 可借鉴的做法

**产品逻辑**：如果做 chat 型 AI 产品的配套环境，别急着做完整 IDE，先做"侧边栏工作台 + 按需加载"：核心保持轻（325KB 级），重依赖（Office 预览、终端模拟）等用户真打开那类文件才加载。这样产品声称"完整工作台"时不会把首屏拖垮。同时把"第三方可注册新面板"作为第一版就有的能力，让生态替你长功能。

## 结论

**值得关注。** 它是这个生态里最"产品级"的侧边栏插件，工程扎实、时机精准，但它赌的是 DSH 生态的长期繁荣，自己没有不可替代的护城河。看它不如看它背后的规律——平台留坑、插件填坑、流量归插件，这套生态动力学在 Agent 时代会反复出现。
