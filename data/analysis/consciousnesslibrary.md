## 一句话定位

把全世界迷幻剂与意识研究的论文收进一个免费开放库：每 20 分钟从十几个学术 API 拉新论文、
去重、按主题归类、自动写通俗摘要，还能跨库提问做证据综合——
并且能分清"LSD 迷幻剂"和"牛结节疹（Lumpy Skin Disease）"这种同名歧义。

## 做这个东西的人

HN 上发布（Show HN，30 分/12 评），作者自述刚念完"迷幻剂与意识研究"硕士，
做研究期间想要这样一个库，于是自己动手；中间搁置一年，实习导师建议捡起来认真做。
项目注册为 501(c)(3) 非营利组织，法律实体 Mindscape Collective，目前由作者自掏腰包运营。
pool 里记录的 builder 是 `elliotec`。

_判断：这类"读完整个领域文献"的库，只能由真的念完相关学位、真的在用的人做出来——
不是技术门槛，是"知道该收什么、知道怎么才算收齐"的门槛。作者恰好两头都占了。_

## 它到底能做哪几件事

- **聚合去重** → 从 PubMed、OpenAlex、Europe PMC、bioRxiv 等十几个学术 API 每 20 分钟抓一遍，自动去重
- **相关性判题** → 用"廉价关键词预筛 + LLM 评分判收/拒"两段管线解决歧义：LSD（迷幻剂）vs Lumpy Skin Disease、氯胺酮治抑郁 vs 给猫麻醉，判错就混进库
- **通俗摘要** → 每篇论文配"Study at a glance"：研究设计、样本量、关键发现，用大白话写
- **主题组织** → 按迷幻剂、实践（冥想）、体验、人文学科、神经科学分类，35,787 篇分布在 37 个主题
- **证据综合** → 主题页有证据概览，也可以跨库提问，AI 综合后指出共识、冲突点和未知区
- **临床试验追踪** → 每日从 ClinicalTrials.gov 刷新试验招募状态、阶段、入组人数、赞助方
- **全库地图** → 每篇论文一个点，整个领域分布一目了然

**它明确不做**：不做商业检索平台，无广告、不登录可读全文摘要；"自由提问生成综合"需要免费注册。

## 它在替代什么旧行为

以前研究迷幻剂领域，要分别去 PubMed、bioRxiv、ClinicalTrials.gov 各自搜索，
手动去重、手动读几十篇摘要找共识和分歧，做完一个主题的文献综述基本以周计。

这个库替代的是三件体力活：**跨库搜索**（一次查全）、**人工读摘要找共识**（证据综合直接给出
"哪些结论一致、哪些还在吵"）、**跟踪临床试验**（每日自动刷新替代每周手动刷）。

## 商业模式

**非商业。** 501(c)(3) 非营利，免费、无广告、读内容不需要注册，靠捐赠（Stripe/PayPal/
Buy Me a Coffee）维持，作者自掏腰包。

_判断：这不是生意，是基础设施。但"用近零成本把极窄领域的完整语料做成免费公共品"这件事本身，
对做垂直 AI 产品的人是个信号——这类资产的价值在别处兑现（影响力、数据合作、基金支持），
不在订阅费。_

## 硬数字

- **35,787 篇论文 / 82,200+ 作者 / 37 个主题**，每日增长
- 基础设施：Rails 8.1 + 单个 Postgres（同时承担全文搜索、向量、任务队列）+ $24/月
  DigitalOcean 单机（刚从 $12 档升级）+ Kamal 部署
- **全部 LLM 花费约 $28**（DeepSeek-V4-Flash），大头是一次性回填，之后还在下降
- 数据更新频率：每 20 分钟轮询一次十几个学术 API
- 团队：单人为主（站点显示有若干协作者头像）；收入、融资：无（捐赠制）

## 四维评估

| 维度 | 结论 |
|------|------|
| 创始人-产品匹配度 | 本人是该领域硕士，为满足自己研究需求而建，"用户即作者"的标准形态 |
| 产品洞察力 | 抓住了"极窄领域完整语料是护城河"；相关性歧义（LSD vs 牛结节疹）是此类库的生死线，处理得很早 |
| 技术实现质量 | 单 Postgres 扛全文+向量+队列，$24/月跑全量，工程克制到教科书级别 |
| 市场时机 | 迷幻剂研究复兴 + 开放学术数据运动，正是公共基础设施的空窗期 |

## 判断

**这是一个"以极低成本把极窄领域做成完整语料"的样板，商业价值不大，机制价值很高。**

最值得抄的是它的**相关性管线**：先廉价关键词预筛，再用 LLM 评分收/拒。
听起来朴素，但作者明确说"相关性是最难的部分"——通用搜索在这里会失败，
因为 Lumpy Skin Disease 里也有 LSD，靠向量检索分不清语义归属。
两段式管线把成本压到全库只花 $28，这是可以迁移到任何垂直语料库的配方。

**它做对的一件事**是注册成非营利而不是公司。窄领域公共库的信任门槛很高，
"不卖数据、不卖广告"本身就是内容的一部分。

**局限**也明显：单人运营、捐赠制、无留存指标公开。这种项目最大的风险不是产品，
是维护者精力——一旦作者毕业就业，更新频率会掉。

## 下一步看什么

① 论文数量是否保持每日增长、更新频率是否兑现"每 20 分钟"——维护在不在线
② 注册用户数和"自由提问综合"的使用量是否公开——有没有真实使用，还是自娱自乐
③ 是否出现机构合作（大学/基金会/期刊）——从个人项目走向公共基础设施的转折点

## 可借鉴的做法

**产品逻辑**：任何垂直领域都可以复制"完整语料 + 通俗摘要 + 证据综合"三件套。
关键动作是先把"怎么算收齐"定义清楚（订阅十几个 API、每 20 分钟轮询），
完整性比检索质量先成立。

**话术**："The world's psychedelic and consciousness research, in one open library."——
用一个"全部收进来"的承诺定义产品，而不是说"我们数据库很大"。

**定价结构**：无。但"非营利 + 捐赠 + 自掏腰包"对需要公信力的窄领域工具是可参考的成立方式。

## 结论

**值得关注（作为机制样本，而非商业标的）。** 语料完整、成本极低（$24/月 + $28 LLM）、
两段式相关性管线可直接迁移。它证明了"一个人 + 一台 $24 服务器 + 几十美元 LLM 花费，
就能建成一个领域的公共基础设施"。商业上别指望它，机制上值得抄。
